# 怎样继续学习并留下可用经验

> [返回学习地图](README.md) · [来源地图](00-source-map.md)

每次从一个具体难题出发，例如“友好的话为什么像说教”“同样的句子什么时候会讨厌”。先找能回答问题的原始材料，再补一个可能推翻首选判断的来源。论文、训练示范、创作者经验和产品案例都有用，但各自能证明的事情不同。

## 一张资料卡

| 字段 | 写法 |
| --- | --- |
| 来源身份 | 作者、年份、标题、原始URL、专题内稳定编号；转载只作访问路径 |
| 阅读范围 | 全文／指定章节／摘要／搜索索引／视频具体片段；访问失败如实记录 |
| 它实际做了什么 | 研究对象、情境、方法；或创作者实际示范了什么 |
| 最值得留下的一点 | 简短转述，有范围、不泛化；不大段复制原文 |
| 反证与局限 | 不显著结果、替代解释、样本、混合变量、文化或载体差别 |
| 本产品怎样借鉴 | 指向一个具体入口、一条例句或一个审稿动作；明确这是推论 |
| 什么不采用 | 不适合本产品目标或表达能力的部分，说明原因 |
| 使用状态 | 研究参考／原创练习／已写入PRD；真的落地再补代码与验证链接 |

一张卡无需很长。只有摘要时不填想象中的实验细节；不同来源都转述同一项研究时，不把网站数量算成独立证据。搜索访问日期与论文发表年份分别记。

## 一条经验卡

写下“具体问题→当时处理→实际暴露的后果→现在采用的方法→仍可能不适用的场景”。例如删短句库后，高频入口只剩几句，这可以支持以后同时审查入口容量；不能支持所有句子都必须变长。

样句标为原创练习并注明适用情境。先有让人愿意听的具体内容，再用心理学检查分寸；不要把理论名称当成台词质量证明。需要读者回复才能成立的示范，只学判断方法，不直接放进单向气泡。

## 文件怎样维护

新增事实与反证放进对应专题；稳定的编辑经验再提炼进05。改产品决定时回写PRD，别在学习目录悄悄定义另一套触发、随机或亲密关系规则。原记录保留日期，修改既有判断时写出是什么新证据改变了它。

资料失效时先找作者、机构或存档的合法替代链接，并记录替代路径。没有继续访问到原文就保留阅读限制；不要把以前看过的摘要改写成已重新核验全文。
