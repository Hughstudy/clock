# 番茄是个番茄 · 学习与经验

这里保存项目可以反复借鉴的研究、示范分析、创作练习和返工经验。先按问题找专题，再看来源和适用条件；正式产品决定仍在[PRD](../prd/README.md)，已经完成什么看[工程计划](../../PLAN.md)和验证报告。

## 怎么把学习用进开发

查到一项资料后，先写清它研究什么、读到了哪里、有哪些限制。再写本产品可以借鉴什么，并附一个具体例子。准备采用时，把决定写回对应PRD模块；实现后给出代码和验证依据。来源、建议、采用和验证是不同状态，不能省略中间判断。

本目录保存简要分析、原始链接和原创练习，不镜像受版权保护的论文、课程、影视对白。旧研究保留日期及当时结论；新证据可以修正经验，不覆盖历史。这里是知识资料，不是新的任务分工板。

新增专题放在独立子目录，并在本页登记；新增文件也要进入该专题的README。`python3 scripts/check-prd-docs.py`同时检查学习目录的地图、相对链接和锚点。工程计划与验证报告继续使用英文，本目录的产品学习与中文样句保留中文。
