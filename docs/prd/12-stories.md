### E.12 新章交接模板与填写样例

先按[角色关系与快乐来源](01-product.md#product-soul)及[共用创作基准](10-character.md#character-basis)写清：**伙伴想要什么 → 怎样尝试或选择 → 发生什么变化 → 怎样回应 → 留下什么。** 这是因果检查，不是五个必做动画。换一个道具但动机、变化与结果都相同，不自动算一章新故事；不要求每章有反转，也不把角色生活缩成替用户完成的任务。下列两例共用同一套入口与计时规则，书桌章仅作跨场景检验样稿。

| 同一意图或事实 | 厨房 · 调一碗合口的汤 | 书桌 · 给松散的书页找个家 |
| --- | --- | --- |
| 开始 ACT-A05，带入前情 | 前一章立起的食谱还在。伙伴拿勺，想知道原汤合不合口 | 桌上已有昨日压平的纸页。伙伴翻开旧书，纸又滑出来 |
| 已达一次尝试 ACT-E01 | 尝过原汤，食谱边写下“有点浓” | 试过短夹子，发现翻页会卡住，留下夹过的折痕 |
| 此时暂停 ACT-A06，稍后继续 ACT-A07 | 勺搁稳，批注可见。回来根据批注试半勺清汤 | 短夹搁在折痕旁。回来从这个位置试宽纸带 |
| 留记号 ACT-B01、求鼓励 ACT-B10、去记录 ACT-C01 | 反馈在对应控件，锅里的状态只随有效专注时间变化 | 同样处理。点多少次鼓励都不会自动夹好书页 |
| 截止前确认结束 ACT-A09 | 试味或调好均按实际落点留短章小记，不收集配方、不生成待续 | 夹子尝试或装好纸带均如实留短章，不收集纸带状态、不生成待续 |
| 到期 ACT-E02，下一次再开始 ACT-A05 | 当次留下整页配方，下次食谱已经带着自己的改法 | 当次留下整页装订手记，下次打开书时纸带已在书上 |

每份新章稿填一张表。最低交付内容如下。动作索引查ACT-A／B／C／D组，系统事件查ACT-E组；业务规则见功能与数据规格；只有新道具或新画面时不增加产品按钮。

| 章稿必填项 | 交给开发与验收的内容 |
| --- | --- |
| 入场条件与本章问题 | 内容标识与版本、适用时长、初始／已收集前情、独立起点及再次尝试／重复稿。写明伙伴想做什么，不读取旧段未完进度，无合法稿普通计时 |
| 综合场景与物件留痕 | 声明完整后新增物件、改变既有状态或仅完整章页；列object_key、完整结果、RULE-COLLECT资格、来源、位置、昼夜及互动对象小话。节点过程只存本段，收集事务后才变小屋；每个短章落点有历史摘要 |
| 角色动机与记忆点 | 引用E.11已确认的主性格及轻微笨拙边界，写明本章的具体选择与反应；具体偏好和桥段注明试稿或验证状态，不要求每章失误。台词按E.11.5复用已有画面，不把语气样例转成新增动作清单。不靠新奖励、口头禅或要求用户解困证明角色性格，停下和缺席不使角色受损。创作描述不自动变成运行时字段 |
| 因果与时间 | 每节点写明角色动机、前置事实、有效计时条件、产生的事实及其归属；视觉动作不是写入依据。列适用时长与节点，首节点前也能停；短稿只做范围相符的小事，不从便签内容或点击次数取因果 |
| 暂停、离场与独立再开始 | 每个节点及节点内可安全停驻／继续原段；手动结束留下真实小记，不设计待续事项或跨时长进度映射。下一段独立起点与已有收集不冲突，休息不推进主章 |
| 两种归档与收集 | 手动落点的短章句图、到期完整结果句图分开；短章不收集，完整且保存成功按章稿进入生活积累。不每章添物，不靠动画回调授予；已收集后文需要哪些事实须明确 |
| 末态、重复与注意力 | 标明首次事实、可变现况和每次事件，写清末态后的合法重复稿与目录身份；角色为什么愿意再做，而不是复刻第一次。仅看开场与结果应可理解，输入／确认／阅读时让位；不靠随机稀有内容或未来更新补闭环 |
| 其他动作如何表现 | 复用休息、触摸、便签、鼓励、导航、设置规则。默认局部回应或静默，只列本章确有必要的动作变体。分别给出静态、隐藏后返回、后台到期和待保存状态的呈现 |

验收时先按动作编号操作，不给试用者讲故事，再请对方指出“我点了什么、现在时间在不在走、伙伴做到哪儿、下次还能找到什么”。操作含义要靠入口和结果读懂，不能靠读完一篇新手教程。

下面是 DAY04 的试做卡。角色动机是继续读自己感兴趣的书；记忆点是用车票作书签，遇到喜欢的段落会回读，而非为了表扬用户去读书。配置字段用于统一各窗口的语言，具体数据布局见[数据对象与字段](05-data-fields.md#database-design)。文本属伙伴自己的故事，用户便签、小步骤不进入选章或故事内容。

```yaml
id: DAY04
content_version: 1
status: shortlisted
intent: 把正读着的这一章看完
entry: 读取书的身份、真实书签和可用的阅读位置
beats:
  - {at: 0.00, scene: 从车票书签处打开书, held: 当前页}
  - {at: 0.25, scene: 读到并回看喜欢的一段, held: 夹在这两页之间的车票}
  - {at: 0.65, scene: 阅读进入本章后一段, held: 已读到的段落}
  - {at: 0.85, scene: 把车票移到下一章并合书, held: 更新过的书签}
paused: 手留在原页，书签和剩余时间都在。继续沿用原落点
manual_end: 按实际落点留短章小记；不更新小屋书签、不收集、不生成待续
deadline: 自然到期且完整结果可信，归档完整章页；同事务提交章稿规定的收集
world_effect: 仅符合收集条件时更新小屋书签；末章完整收集才把书标成已读完
repeat: 新段从合法的已收集书签或独立重读起点开始；不接旧短章进度
static: 翻页动效可省，固定书页和书签的相对位置仍能读懂
```

样例比例只用于本章完整样稿。25分钟样稿在6分15秒第一次重读，21分15秒合书，余下时间保留结果；5分钟版可在1分15秒和4分15秒呈现相同的两个节点。**1分钟短章须重写要做的小事**，例如起因是“有一段想再读一遍”，经过是“翻回做过标记的那页”，结果是“读懂了那一句并夹好书签”。这一章仍有完整结尾，只推进真正读过的段落。120分钟可增加安静阅读时间，保留少量关键节点。DAY03 的短章可从已知的片尾前续看，第一次使用则选择一段独立的片头短片，不声称看完未看的集数。DAY25 可从已生根的枝条开始，不把现实几天的长根硬塞进一分钟。

**暂停与新段的区别。** 同一25分钟稿首节点在6分15秒：A运行3分钟暂停，再继续3分15秒可以达到节点；若A已手动结束，B就是独立新段，不能继承A的3分钟。A在21分15秒合书后提前结束，历史如实保留合书的小记，但不收集本段书签；自然到期且保存成功才更新小屋书签。下一稿只引用已收集前情，不能把未收集小记当已推进后文。

**逐章交接附状态表。** 至少列“独立入场事实／适用时长／节点与原段暂停恢复／安全离场姿态／手动短章结果／到期完整结果／收集变化／合法再次尝试与重复稿”。取消跨段未完事项及节点映射；缺支持时长、真实结果或重复路径仍不能标交付完整。对应[T-CA02—04](07-acceptance.md#causal-longterm-tests)。

制作成本按E.14评估。读书的关键画面是车票书签移动，分盆是白根从杯里入土，清桌是逐步露出的桌面。具体演法与暂停规则按对应章稿及动作索引执行。

### E.13 当前内容与交付要求

| 章节 | 作用与关键事实 | 制作状态 |
| --- | --- | --- |
| DAY05 清出窗边的小桌 | 为伙伴自己的阅读腾位置；过程可暂停／继续原段，完整到期并保存后才把桌面变化收集到小屋 | 首章试做，按正文范围验收 |
| DAY61 给窗边的多肉浇水 | 看盆土、浇水、收壶；已有多肉不作为新奖励，不因缺席变坏或反复浇同一盆 | 根据首章成本与试用决定扩展 |
| DAY04 读完手里这一章 | 从真实车票书签继续，留下已读位置；读到章末与整本读完分别定义 | 根据首章成本与试用决定扩展 |
| DAY31 相框／DAY25 薄荷小盆 | 为“自然留下一个新物件”选择其一，必须交付来源节点及前后构图 | 选题待定，不预置为已获得 |

每个落点可暂停、继续原段或提前结束；结束后无待续事项，短章可回看但不收集。完整成果保存后可进入后继，已收集首次成果不重发；重复稿须独立、有合法前情，不能只写“以后可重复”。

### E.14 六项成本与本地预算

每章按“首版交付＋一次内容维护”估投入，记录设计、美术、工程和测试的总人时；新增机位、分支、资源或兼容要求时重估。首章实测后再估后续章节，不保留旧题材的人日推算。

| 成本项 | 必须算入 |
| --- | --- |
| 稿 · 剧情与交互 | 动机、已收集前情、独立短／常规稿、手动落点、完整结果、收集条件及重复稿；不制作跨段未完事项 |
| 图 · 美术与构图 | 固定机位、道具与接触关系、各状态和手机适配 |
| 动 · 显示与动作 | 必要短动作、静态替代、暂停与隐藏后恢复 |
| 记 · 状态与保存 | 真实事实、归属、提交边界、恢复与旧版本映射 |
| 验 · 集成验证 | 到期／提前结束、并发、离线、静音静态、历史和真机 |
| 养 · 内容维护 | 一次普通变化及旧记录兼容；后续每次变化另估 |

公共的计时、章节执行、存储恢复和离线能力单列，不重复计入每章。片段依附已制作章节时计新增投入；宿主未制作时，必须加上宿主的完整成本。

| 成本来源 | 这一批的默认办法 | 什么时候换方案 |
| --- | --- | --- |
| 画图、动画和运行负担 | 每章先画一个固定机位的开场、可停驻的经过、截止前已成立的结果。三张可用同一构图的局部变化组成。每章保留一个值得动的瞬间。只在必要时加一次手物接触，暂停、隐藏、减少动态直接显示对应静姿 | 三态在小屏上说不清，先改镜头或缩小事件范围。必须靠长视频、持续粒子、整屏布料、精密骨骼或新增角色才能成立时，移出本批 |
| 文案、内容量与声音 | 首发只准备一个普通稿、一个短稿，以及真实到期和不同手动落点的简短摘要。优先让姿态和物件讲明动作；台词按E.11.5适配已有画面，不反向增加表演负担。生活故事可静音理解，既有计时提示音按产品偏好独立控制 | 新集数、新歌曲、新照片、新拼图都算新增制作。需持续采购授权、录音或每一段都画新品才不腻的方案先留稿 |
| 记录、维护与旧历史 | 会话复用的是业务身份，一次操作只结算一次。每章标出哪些能从章版本及节点推得，哪些必须保留，例如书号、相框位置。历史只留可还原当时画面的事实，不存整幅房间、图片或动作轨迹 | 存储虽小，但需要多对象分支、回滚或旧版本特殊解释时，提高「记、验、养」档。若删掉该字段会让暂停或下次开场说谎，保留字段，先砍另一处装饰 |
| 包体、离线和设备适配 | 量起始版本与样稿版本的生产资源总差、离线缓存总差、手机运行和历史存储。首批单章独有的图形、样式及内容配置暂以压缩后8 KiB为复核线，三章连同新增故事程序以32 KiB为复核线。压缩传输体积、设备缓存占用、用户记录分开报 | 超线先定位是多画一景、重复媒体还是程序负担；可降为单机位、轮廓替换或静态。需要留住关键趣味点时回到逐项预算重新取舍。两条体积线都是未实测的试做目标 |

不能削掉的成本包括稳定主控、静态可理解、原段暂停恢复、手动短章如实归档、自然到期完整章及收集事务、下次能认出已有生活。未完整不收集但记录不丢，不为省制作把短章改成失败。达不到单章清楚可用时缩小题材或暂缓独立成章。

用户记录、离线图稿与运行消耗分别测量。先交付一章并记录稿、图、动、记、验、养的实际投入，再决定内容规模；体积复核线为试做目标，不能当实测结果或报价。

### E.15 多肉章节点样例

**以一段25分钟多肉章为例。** 进入条件为已收集的桌面可用、盆可照料。0分备壶，6分看过盆土并移壶，15分本段画面浇湿，21分安放，25分自然截止。中间节点只属于本段；到期且完整结果保存后，“已照料”才进入小屋收集。几秒倒水动作只出现一次，其余时间可安静停住。

| 实际经历 | 用户看到什么 | 记录如何变化 |
| --- | --- | --- |
| 运行8分钟，点暂停，离开3分钟再回来 | 17:00，「继续专注」，壶在盆边，土未湿 | 本段有效投入仍为8分钟，没有结束记录、完整次数或「已浇」事实 |
| 从此继续2分钟后确认结束 | 小记“给壶找好了位置”，实际10分钟，无待续提示 | 一次参与、一条10分钟manual、0次到期；过程保留历史，不收集、不传下段，暂停3分钟不计入 |
| 另一路径：浇过水后，第16分钟提前结束 | 小记如实显示本段曾浇湿，当前小屋不新增本段养护成果 | 一条16分钟manual，0次到期，短章不收集；新段独立选章，不承接本段未收集落点 |
| 另一路径：原段走到截止或后台跨截止 | 完整照料章页，保存成功后小屋留下养护变化；休息仍须明确开始 | 一条25分钟deadline，一次完整到期，收集只提交一次；重复刷新／别窗核对不再发放 |

各路径使用的是同一个起点，互为替代，不能将四行所列分钟相加。历史归档日期和时间汇总沿A.5，启动时区固定；调系统时间不得导致负数或重复结算。
