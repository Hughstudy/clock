| 动作与目的 | 对象／条件 | 成功后的影响 | 未成或失效时／去向 |
| --- | --- | --- | --- |
| <a id="act-c03-1"></a>ACT-C03.1 展开／折叠汇总：调整信息密度 | 本页汇总可见状态；只读也可查看 | 仅展示层级改变，范围仍可辨；不改公式、记录或业务状态 | 不依赖写入；隐藏内容不可继续被焦点访问，焦点回触发控件 |

| ACT-B06 退出编辑：返回原来目的 | 按草稿规则保留；安全保留可直接离开 | 不暗中正式提交；恢复草稿须用户主动打开键盘 | 未可靠保存说明风险并保留本次副本；冲突、明确放弃或替换草稿才请求必要决定，不每次切模式都重复确认 |
| ACT-B08 收起／放回待看：调整放置状态 | 有效、可写的未删除条目；一次明确意图设置目标状态 | 只改待看状态，总想法数不变；本版全部想法仍显示原条目，不改日期或排序 | 待确认只标处理中，不先移走或报成功；失败保留原状态，就地可重试 |
| <a id="act-b09-1"></a>ACT-B09.1 删除想法：不再保留 | 指定条目／版本／世代；有未交输入依A.2处理 | 删除确认保存后从正式视图和想法计数移除；计时、故事不变，提供原规则的撤销路径 | 失败不隐藏原正文或报已删；未知先核对。成功移除后就近焦点，不跳顶部 |
| <a id="act-b09-2"></a>ACT-B09.2 撤销删除：恢复误删 | 同条目、同删除版本及世代；删除成功后未满10分钟，沿RULE-UNDO | 恢复原ID、归属、时间、正文和删除前待看状态；按原排序出现，计数恢复一次 | 过期、被替换或发生冲突时如实说明，不新建一份或盖掉新状态；不强制滚到恢复项 |
| ACT-B15 取消一句收藏：解除选择 | 确实存在、可写的主动句子收藏关系 | 成功后移除该关系；如显示主动收藏句数则按该集合更新，不影响欢迎笺、已获内容或故事 | 失败保留原收藏状态；成功按就近焦点规则返回，不把同动作套到所有收藏内容 |
| ACT-C09 隐藏纪念展示：调整干扰 | 已有展示偏好，作用范围明确；不新增逐项隐藏入口 | 只改偏好，已有所得可按原规则主动查找，不影响资格或计时 | 失败保留原偏好；不诱导用户重新开启 |
| ACT-D01 重试保存：落实原变更 | 原操作ID／对象／版本／世代，先核对是否已成功 | 原操作最多生效一次；按影响对象更新记录、适用计数或偏好 | 已失效则先核对，不盲目重放；失败保留本次副本。历史读取失败应重试读取，不调用保存 |
