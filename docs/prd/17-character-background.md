## 1. 故事正文

在住进果园边的小屋以前，蓝色小伙伴喜欢在附近走走。有时坐一小段车，有时沿着坡下的路，去看一棵从没走近过的树。它通常带一本书，书里夹着一张自己画的路线图。

那张图不太适合借给别人。上面有路口和小桥，也有“这里的树影像一把梳子”“背风，可以翻书”。有一回，它把最好看的那棵树画得太大，回去的路只好从纸背绕过去。它自己倒认得。

它也会照着路线走到目的地。只是回来以后，说起一趟出门，最先想起的有时是一片卷起来的叶子，或者一个杯子放在石台上，响得和放在木桌上不一样。它喜欢这些没有写在路牌上的小事。

果园边的那扇窗，就是这样被它记住的。

有一回，它在那间小屋歇脚，从窗前看见两道山坡。它往旁边挪了挪，近处的坡挡住了远处的一小块，看起来像把一座山收进了另一座山的口袋。它觉得有意思，在图上添了一扇窗。后来经过这里，它又去看那两道坡。有时看一眼就走，有时索性在附近翻几页书。

等到想找一个固定住处的时候，它选了这间小屋。屋里已经有能用的桌子、架子和杯子，外面就是熟悉的果园。它喜欢那扇窗，也喜欢伸手就够得着的小桌。住进去，并不妨碍哪天想出门时再走走。

刚搬来时，它试过把喜欢的东西全摆在窗前：书、杯子，还有一盆小植物。摆好了才发现，山坡被挡住了，自己的胳膊也没地方放。

它把杯子放回桌上，把书移到顺手的一边。植物留下，稍微偏一点。左右不太对称，不过山坡露出来了，书也拿得到。它坐下来，翻开刚才没看完的那页。

住久了，它有了一种很喜欢的下午：把茶泡好，书放在刚刚好的位置，自己却先捧着杯子看一会儿窗外。书也不急着收起来，等会儿还想看。

那张路线图还夹在书里，纸背的路也还在。它没有打算把附近每个角落都画进去。哪处有趣，便记得哪处；想再去，就再去。

你认识它的时候，这样的生活已经开始了。你做自己的事，它在旁边读书、摆弄小东西，或看一会儿天。碰巧有个发现，它愿意说给你听。没有话的时候，共处一会儿也很好。

小屋是它自己喜欢的住处。你来时，它很乐意和你待在同一段时间里；你离开时，这份自在也不需要你替它维持。

## 2. 这是谁，以及它现在想要什么

**一句话人物定位：** 一个住在果园边、爱走小路的蓝色小伙伴，习惯把偶然发现的趣味，带回自己伸手够得着的日常。

“把小小的远方带回家”是本稿标题，不是产品名、角色名、口头禅或必须完成的使命。“远方”可以只是窗外的山坡、书里的一段话或一只纸船，没有远行地图、全收集目标和寻找身世的悬念。

它现在想做的，是把身边这一小块生活过得有自己的意思。好奇可能使它试一下，也可能让它再看一眼就满意。家已经好好存在；没有“建成小屋才能幸福”的终点。出门与待在家是同样有效的喜好，故事不赞美更长时间的停留，也不把安静写成纠正活泼的成长课。

| 人物层次 | 本稿的具体内容 | 怎样避免变成空泛形容词 |
| --- | --- | --- |
| 过去的一项选择 | 因为喜欢反复见到的窗景与顺手的小桌，主动选择住在这里 | 住处有私人理由，家在用户出现前就成立 |
| 留下的观察习惯 | 先看普通东西有什么吸引自己的地方；同一处也可能值得再看 | 阅读、观察植物与看云有共通的兴趣，不需要新道具证明 |
| 有趣的小偏心 | 自己画得懂的路线图不必让别人觉得标准；舒服的摆法不一定对称 | 偏好具体且无害，不让别人迁就、不把混乱当可爱 |
| 本稿采用的小矛盾 | 想把喜欢的东西放近一点，却也想给眼前的活动留空间 | 可以取舍，也可以保持原样；不是每次都演“失败后成长” |
| 能干的一面 | 会照料自己的生活、顺利做熟悉的事，能处理小失误 | 用户不是导师、饲养者或救场者 |
| 玩心 | 会好奇纸船和积木能成什么样，也能单纯享受泡泡 | 没有实用成果的乐趣也成立，不把每项活动写成实验报告 |
| 亲近的方式 | 愿意分享自己的观察，也能各做各的事 | 不探知用户心情，不索取回应，不靠等待产生亏欠 |

这里承接了[人物弧光讨论稿](15-character-arc-proposal.md)对“小主意有一点偏心”的探索，但没有把那项提案追认成已确认性格。本稿的地图、窗景记忆和搬入经历同样是新创作；已确认基准仍是好奇、有自己的小主意、认真但不较劲，笨拙只作点缀。

## 3. 世界的边界

小屋、工作间与露台连着同一片果园。附近有可散步的小路；背景往事可以提到短途乘车，不据此增加车站、村庄、旅行界面或其他角色。世界足以容纳它的日常，不需要先写种族、国家、职业体系和魔法规则。

它是已经能独立生活的非人类小伙伴。外观保留现有的圆润蓝色身体、浅色肚子、小脚、头顶小簇与短而有表现力的胳膊。具体物种、名字、年龄、性别与正式材质保持开放。蓝色不需要由海洋、悲伤、用户注意力或夜间能量解释；身体不会因这篇背景获得飞行、变水、发光或伸长手臂的新能力。

背景中的小桌适合它使用，因而它倾向于把东西放在够得着的位置。这是人物生活的解释，不是把历史穿模、长臂或物件悬空合理化。旧鲸鱼安装图标的来源信息仍按原规则保留；新故事不替那些资产改写出处。

## 4. 三种事实要分清

| 类型 | 本稿中的例子 | 后续可以怎样用 |
| --- | --- | --- |
| 固定的虚构往事，本轮新提案 | 短途散步、自画路线图、喜欢窗景、选择住处、搬入时的一次摆放 | 若之后采用，可作为角色在认识用户之前的简历；不用用户计时证明，也不生成用户记录 |
| 已有初始布景与活动能力 | 果园、小屋、桌子、书、杯子、植物；当前十一项活动 | 已存在的东西继续是初始布景或活动素材，不改称用户刚获得的奖励 |
| 用户使用后才成立的共同经历 | 某次专注／休息记录、当次纪念画、未来合资格故事结果 | 只引用实际状态。现有纪念画可来自已保存的手动结束或自然到期记录；未来故事成果另按[收集规则](02-features.md#rule-collect)判断 |

**路线图只存在于本篇创作稿。** 本轮没有把它做成画面、初始物件、收藏或可点击入口。现有阅读画面使用的是丝带形书签；未来 DAY04 稿里的旧车票也是另一项尚待制作的内容。不要把图、丝带和车票说成当前同一件已实现物品，或为串联它们补写用户不存在的历史。本稿也不强制后续制作路线图：去掉它的可见道具，人物的观察习惯仍能用于现有场景。

“有自己的生活”是创作上的自主性。它不表示应用关闭时在后台旅行、发现物件、写日记或推进剧情。回来时仍只恢复真实计时与已保存内容；背景叙述不代替存储事实。

## 5. 与当前十一项活动的逐一核对

以下写的是背景能够提供的**内在理由**，不是本轮增加的动作、自动台词、剧情节点或动画制作任务。活动 ID 和名称沿用[当前目录](../../src/data/scene-copy.ts)。这些活动现在就全部可用，没有按身世先后解锁的顺序。

| 现有活动 | 这个伙伴可能在意什么 | 保留的事实边界 |
| --- | --- | --- |
| F1 准备一餐 | 想做一锅自己喜欢的汤，熟悉的搭配也值得再做 | 当前是倒入配料、搅汤；没有已实现的品尝、配方收藏或用户喂食 |
| F2 小花盆 | 对叶片的形状与变化有兴趣，愿意看着它 | 当前双手放在桌上、视线关注植物；不是 DAY61 的检查盆土和浇水 |
| F3 一起读书 | 有一段还想看，喜欢的内容可以重读 | 保留当前书与丝带书签；本稿不替换为地图或车票，不谎称记录了阅读进度 |
| F4 一杯茶 | 喜欢准备后安稳拿着杯子的那一会儿 | 茶在前段制好，约40%后持杯；不为了表现好奇一直重新倒茶 |
| F5 吹泡泡 | 对轻飘飘的东西会去哪里感兴趣，也只是觉得好玩 | 使用现有泡泡棒和支撑关系，不加追逐、飞行或必须戳破的任务 |
| F6 纸船 | 喜欢把普通纸变成一件可以玩的东西 | 现有纸船进入浅盘；不把它改成远航工具或到达小屋的交通工具 |
| F7 积木塔 | 想看看一个自己喜欢的摆法立起来是什么样 | 塔可以顺利搭好；不加入倒塌、反复重搭或修复义务 |
| F8 看星星 | 喜欢看看近处之外的世界，不急着弄懂每颗星 | 星月是该活动的画面内容，不设星族身世、夜间专属生存条件或星图收集 |
| R1 伸个懒腰 | 身体舒展开本来就舒服 | 休息自由可用；不拿拉伸作完成工作的奖赏 |
| R2 看云 | 有时愿意什么也不动，只看形状经过 | 不要求记录发现、猜出正确形状或看完整段才算有收获 |
| R3 暖暖的饮品 | 喜欢熟悉的温暖，不必每次尝试新东西 | 不产生饥渴值，也不需要用户递送或补充饮品 |

十一项都能找到理由，但不需要每项都说一遍自己的身世。阅读可以只是阅读，休息可以没有新发现；背景负责让选择连贯，不把简单活动变成连载说明书。

## 6. 留给以后动画的创作依据

本阶段只交付“它为什么这样做”。以后另行评审动画时，可以据此判断一个动作是否像它，不从本表直接建立开发清单。

| 内在缘由 | 以后评稿时应能读出的意思 | 不能由此推出的要求 |
| --- | --- | --- |
| 留意熟悉东西里的细节 | 注意力有具体对象，观察后可以回到当前事情 | 不持续扫视，不强制每个物件都有反应 |
| 爱试一个自己的办法 | 行动是它有所选择，有时还挺满意 | 不固定每段表演“灵机一动”，不加成功音效或看向用户求夸奖 |
| 东西要放得顺手 | 手、物件、桌面之间的关系可信 | 不拉长胳膊，不让主控移位，不借道具穿模制造笨拙 |
| 喜欢现在这样也可以 | 活动结束后，安静的姿态本身有意义 | 不为“活着”不断加动作，也不把无表情判为消极 |
| 能自己处理轻微失误 | 偶尔调整仍有自主判断，成功时也可靠 | 不新增固定跌倒／洒汤循环，不因用户结束而演失落 |

静态图仍应表达“它正在关心这件事”或“它现在很自在”。眼神、姿态和手中已有的东西足以作为候选载体；是否制作、如何安排、接触几何和播放时机留待动画更新。主逻辑继续拥有计时、保存和事实，动画没有改变它们的权限。

## 7. 声音试写与删改依据

以下只是背景稿的语气试写，不写入现有句库，不新增触发。

| 有事实依据时的情境 | 候选一句 | 判断 |
| --- | --- | --- |
| 作者背景介绍提到那张路线图 | “这棵树画大了。回去的路在背面。” | 有一点自己的办法和轻微笨拙；只用于有地图语境的文字，不让现有画面凭空拿图 |
| 正在读已有的书 | “这段我还想再看一遍。” | 愿望足够具体，无需额外物件或复杂表情；不声称已经回读 |
| 确实在捧着制好的茶 | “我喜欢拿着杯子的这一会儿。” | 普通的享受也像它，不把休息解释成教训 |

删去的写法包括“只要你专注，我就能继续旅行”“我一直在这里等你”“不完美也是最好的自己”。它们分别把身世变成计时依赖、制造等待债务，或让人物替产品讲道理。

对这篇背景的纸面反查也做了三处收缩：没有把散步写成必须走遍的收集任务；没有把住下来写成战胜浮躁；没有要求把搬家往事拍成序章。路线图只留一个记忆点，不继续增加纪念品、亲属、导师或谜团。

## 8. 本轮交付与下一阶段边界

已完成互联网来源研究、现有形象与十一项活动核对、背景正文、人物动机和后续表演判断依据。新故事足够供评阅，不要求先补名字才能使用。

本稿仍需用实际阅读反馈判断是否令人喜欢、是否有辨识度。纸面核对只能说明与现有约束相容，不代表已做用户测试，也不能证明动画效果或长期陪伴效果。后续最有价值的检验是：只看正文，能否说出它为什么住在这里、喜欢什么、有什么自己的小意思；不看背景，现有普通活动能否仍然自然成立。

本轮只改产品文档与入口。没有改应用源码、美术、动画、台词触发、计时、保存、初始物件或 DAY 章稿；也没有把身世设为必须阅读的开场。用户之后若要更新动画，再以选中的背景内容建立具体方案。
