## 1. 故事正文

在住进果园边的小屋以前，它就想有一张自己的桌子。

那时候，它喜欢在附近走走，带着一本书和一只小木箱。箱里有杯子、几张纸，还有当时想摆弄的东西。遇见合意的地方，它会把木箱放稳，箱盖便是一张临时的小桌。杯子放一边，书摊开，再给胳膊找个位置。它很会安顿自己，只是地方常常比想的少一点。

它出门时有自己的路线，沿路却常遇到计划以外的趣味。一片叶子漂过桥下，在水里转了半圈，它想试试纸船会不会也这样转。看见两道山坡叠在一起，回来摆那几块积木时，又会想起山坡的样子。

这些念头有时被它画在路线图上。有一回，一棵喜欢的树画得太大，回去的路只好绕到纸背。它自己倒认得。

果园边的小屋，它起初只打算住几天。

窗外有两道山坡，门外是露台。屋里已经有书架、杯子和一张矮桌。它坐到桌前，把书打开，试着将两只胳膊放下。杯子不用挪到地上，纸也摊得开。它又把杯子往自己这一边移了一点。

一个下雨的下午，它听见露台上的水声，想起了桥下那片叶子。它抽出一张纸，照着记得的样子折了一条船，给浅盘添上水，轻轻放进去。水还没有静下来，纸船便沿着盘边转过去，换了个方向。

它看得很认真。船停下后，它又拨了一下水。这次它知道船会动，却还是很想看看。

天暗下来，它把盘子挪到一旁，在桌上吃了饭。收好碗，书又摊在刚才的位置。那条船留在干燥的盘边，杯子也还在顺手的地方。它翻过一页，接着读。

原定离开的那天，它把书、杯子和剩下的纸收进木箱，合上盖子，又看了一眼窗边。

过了一会儿，它重新打开箱子，把书拿出来，放回桌上。杯子也放回顺手的位置。它试了试，将木箱推进桌下，正好放得下。

那次，它决定住下来。至于出门，哪天想去，木箱随时还能拿出来。

现在，它仍然常有些自己的主意，也有些轻易不肯换的老习惯。正喜欢的书总想放近一点，惯用的杯子也有自己的位置。偏偏有新东西想试时，它又希望桌上宽敞些。它会看看书，再看看手里的东西。有时挪开杯子，有时把新东西放回去——今天还想接着读。

也有许多日子，桌上没有什么新花样。它照熟悉的办法煮汤，泡好茶，捧着杯子看一会儿窗外。它喜欢让一个办法真的奏效，也喜欢事情都放妥之后，手里只剩杯子的那一会儿。

天气合意，它也会翻开那张不太规整的路线图，找一条想再走一次的路。

你认识它的时候，它已经在这里住了一阵子。窗外是果园，桌上放着一本书。察觉你来了，它抬头招呼一下，随后又看向书页。刚才那一句，它还想再读一遍。

## 2. 这个版本里，它是谁

**人物定位：** 一个喜欢亲手试试的蓝色小伙伴，为自己的兴趣选了一个家。小路让它遇见新鲜事，小桌让它有机会把其中一些变成自己的生活。

它现在的愿望是给自己喜欢的事情留一点地方。这个愿望可以落在折纸、做饭或摆东西上，也可以只是让书留在手边。小屋已经适合生活，生活本身也不欠一个需要用户补齐的结局。

| 人物的一个面 | 背景中的来由 | 以后仍可产生的不同选择 |
| --- | --- | --- |
| 好奇有具体去处 | 留意叶子怎样转、山坡怎样叠，偶尔想亲手试一小下 | 观察、试用、重读；也可以看过便满足 |
| 有自己的办法 | 会用木箱安顿自己，图画得随意却确实能带它回去 | 自己安排手边的东西；不必每次发明，也不总是最整齐 |
| 认真而有能力 | 折船与生活照料能顺利完成；奏效之后仍愿意欣赏 | 熟练做事与带着兴致尝试都成立，不靠连续出错证明可爱 |
| 一点笨拙 | 有时高估纸面或桌面的空间 | 偶尔自己挪一挪；这只是点缀，不形成固定笑点 |
| 有可以起小波折的偏好 | 喜欢熟悉东西待在近处，又想给新主意留空间 | 留下、挪开、换用，或今天根本不换；不必每次得到相同答案 |
| 能享受结果 | 选择小屋，是因为喜欢自己的几件小事在同一个地方发生 | 可以动手，也可以安稳捧杯；没有成果的休息同样自然 |
| 与用户平等相处 | 用户认识它时，它已经会安排自己的日子 | 欢迎陪伴，也能继续做自己的事，不监督、不索取回应 |

这里的新矛盾是**熟悉的东西想留近一些，新鲜的念头又想试一试**。它不是需要治好的缺点。它也不必永远先选新主意；把新东西放回去、继续读喜欢的书，同样是有主见。

“把小小的远方带回家”仍只是故事标题，不是角色名或使命。具体名字、物种、年龄、性别和正式材质保持开放。现有蓝色圆身体、短胳膊、浅色肚子、小脚与头顶小簇沿用；身世不添加飞行、变形或无限伸长等能力。

## 3. 这次为什么重写

第一稿的地图、窗景、搬家和喝茶是相邻的生活片段，缺少使下一件事发生的愿望。窗景解释了它喜欢哪里，却没解释这个地方为什么值得它选择。最后直接说明用户不必维持它的幸福，也让故事收尾变成了产品承诺。

这一稿把因果放回人物：早先就想有自己的桌子，出门积累了一些想亲手试的念头，在小屋度过一个有具体内容的下午，原定离开时又打开箱子，把书和杯子放回去。住下来的选择由它自己做出来。纸船顺利浮起来，让它显出能干与兴致；空间的小局限仍能带来轻微趣味。结尾停在一次自然的招呼和它正在喜欢的书上。

地图的趣味保留，但只作个人往事的细节。叙事的中心现在是它选择了怎样的生活。研究帮助确定方法；这次重写是否更有吸引力，仍是需要评阅的创作判断，不能用合规检查代替。

## 4. 给以后表演的依据

背景提供的是人物当下可能在意什么。以后动画评稿时，应先说清它想做什么，再判断表演，不从本节直接建立开发任务。

| 当下意思 | 可以据此判断表演是否像它 | 不必附带的东西 |
| --- | --- | --- |
| “我想看看会怎样” | 注意力落在具体物件，尝试有清楚对象 | 不必每次惊讶、跳起或说出发现 |
| “这是我想到的办法” | 认真使用已有东西，奏效时有一点自己的满意 | 不必向用户邀功，不需要每次犯错 |
| “这本我还想看” | 选择保留熟悉的东西，也能显出意愿 | 不必每段换活动或安排成长 |
| “现在这样就挺舒服” | 稳定的静姿也有生活含义 | 不要求一直动，不把休息写成工作的奖励 |

同一个身体动作会因对象与意图有不同意味，但不靠微表情才能理解。短臂、握持与支撑关系照现有约束处理；停下、结束和保存都不等表演。路线图、小木箱和往事中的纸船不用先做成素材，已有场景也能承接这些动机。

当前十一项活动逐一复核后仍可容纳这个人物：F1汤是生活兴趣，F2植物是观察，F3阅读可有偏爱，F4茶是准备后的享受，F5泡泡与F6纸船是玩心，F7积木是自己的摆法，F8星星是对远处的好奇；R1伸展、R2看云、R3暖饮都能单纯舒服地发生。**不把它们全部改成实验、发明或纪念品制作。** 具体实现差别与来源仍见[研究中的现状核对](18-character-background-research.md#background-current-check)。

## 5. 使用这份背景时的边界

这篇文字里的过去是新提出的虚构简历。路线图、小木箱、短住与纸船经历没有写入应用，也不是用户获得的物件或完成的故事。当前阅读素材仍是丝带形书签；未来 DAY04 的旧车票属于另外的章稿。若以后采用其中任何可见细节，再单独确定它的素材和事实身份。

用户使用后的记忆只来自真实状态：现有纪念画可来自已保存的手动结束或自然到期记录；未来故事成果另按[收集规则](02-features.md#rule-collect)判断。角色拥有自己的意愿，不表示关闭应用后会旅行、填地图、增加物件或推进剧情；暂停可继续原段，结束不留下补做义务。它对用户的善意与用户的时长、停止和缺席无关。
