## 一、产品定位与原则

<a id="product-soul"></a>
<a id="relationship"></a>

产品面向独自工作、学习或处理日常事务的成年人，也考虑成人ADHD相关使用困难：坐下后难以开始，开始后想起别的事，中断后不容易回来。核心任务是**可调节计时、想法暂存、长期回顾**，使用不要求诊断或自建账号。

伙伴有自己的兴趣、动机和生活。它好奇、有自己的小主意，做事认真但不较劲；偶尔有一点笨拙，也可以安静自在。用户不需要照顾它，它也不监督或评价用户。亲近来自熟悉它、看见生活展开和留下共同经历，基本善意不靠专注成绩兑换。

<a id="joy"></a>
<a id="worldview"></a>
<a id="principles"></a>

**安心、自主、事实可信是底线。** 用户可以开始、暂停、提前结束、休息或离开；已有投入和所得保留，缺席不产生损失或补做义务。不看故事、不回应角色，也能完整使用工具。计时只说明记录了多少运行时间，不证明现实任务完成、效率提高或注意力水平。

快乐来自喜欢这个伙伴、看见有来由的生活变化，以及能找回自己的投入。趣味通过角色与内容实现，不增加签到、排行、关系衰减、领取压力或必须盯屏的任务。发生冲突时，用户自主、记录可信和核心操作优先于剧情与表演。

## 二、整体体验与页面

### 2.1 用户打开后看到什么

最终视觉目标以清亮蓝色伙伴和温柔、略带明艳感的写意水墨为主。当前功能原型沿用已确认的圆润蓝色伙伴与现有绘制方案；这不表示最终水墨目标已取消或正式美术已验收。首版生活空间是窗边小屋，有小桌、杯子、书和多肉。时间与操作清楚，场景大部分时间安静，在有意义的节点发生短动作；文字不遮人物面部、关键动作或计时。

| 页面 | 看见什么、能做什么 |
| --- | --- |
| 专注 | 看时间和状态，选择时长并开始；运行中暂停、继续或结束；随时留标记、记想法、主动要鼓励。伙伴在同一画面做自己的小事 |
| 记录 | 四种查看方式：全部记录、只看想法、生活场景、我的收藏。各有自己的内容与查找工具，打开详情后回原位置 |
| 设置 | 调默认时长、声音、动态与场景展示；导出备份、恢复或清空本机数据；查看应用说明 |

底部主导航只有“专注／记录”。设置从专注页固定入口进入，关闭回专注。计时中无操作时，导航和设置随卡片[让位](02-features.md#focus-step-aside)，一次呼出即恢复。输入、阅读和确认使用一层临时面板；这些入口不新增主页面。

<a id="experience-cycle"></a>

### 2.2 一次使用怎样完成

| 阶段 | 用户体验 |
| --- | --- |
| 准备 | 首次默认25分钟；点击时间数字或旁边铅笔打开1—120分钟刻度尺，也可直接输入分钟数。“用这个时长”只更新准备值，“开始专注”才开始；可选填一个小步骤，不需要先选剧情 |
| 进行 | 看剩余时间；伙伴按有效计时推进自己的日常。忽然想到别的事，可留空标记或写想法，然后回来；打开输入不自动暂停 |
| 中断 | 暂停后保留原段，点继续接着计时和本段故事。提前结束先确认，留下真实投入与短章小记；不收集本段故事成果，也不生成下次待续事项 |
| 收尾 | 在原时间与操作区域看实际计时、当次归档和保存状态。自然到期留下完整章页，符合收集条件的故事成果保存后进入生活积累；可明确开始休息或点“准备专注”，不自动开始 |
| 重返 | 有活动段就恢复其真实状态，已到期只结算一次；没有活动段则回准备。旧想法、历史和小屋变化仍可回看，不强制补看剧情 |

### 2.3 各部分怎样配合

**计时提供时间事实，故事提供伙伴经历，记录连接这一次与下一次。** 有效计时推进已绑定故事；想法、鼓励、触摸、阅读和昼夜切换只完成各自用途，不额外推进故事或发放物件。暂停不计入有效时间，休息不推进专注故事。

每段专注有独立计时和故事记录。暂停后继续仍是原会话；会话结束后不保留待续事项，下次独立选章，不继承旧段分钟或节点进展。已经收集的生活事实可作为后续前情。当前小屋呈现初始布景与已收集的生活变化，历史保留当次实际过程；未收集的小记仍可回看。内容做完后有已编写的重复日常，核心工具始终可用。

页面、会话、输入和保存状态分别管理。例如人在记录页编辑想法时，专注可以正在运行，草稿也可能尚待保存；切页不暂停，计时到期不抢走输入，保存失败不能被画成计时仍未结束。

## 三、核心功能

### 3.1 专注计时与休息

默认专注25分钟、短休息5分钟、长休息15分钟；自定义分别支持1—120、1—60、1—90分钟整数。小步骤可空，最多80个Unicode码点。当前选择与设置默认分开，已开始的目标锁定；任何时刻最多一个活动会话。

准备时主动作是“开始专注”；运行时为“暂停专注”，暂停后为“继续专注”。“结束专注”紧邻主控、作为清楚的次级按钮；确认框使用“返回计时／确认结束”。确认期间沿原状态计时，若已到期则按到期结束一次。打开想法、切页、锁屏或关闭应用均不隐含暂停。

专注结束后显示实际投入和单独的保存状态。“准备专注”只回准备，“开始休息”才启动所显示时长的独立休息。每逢第4、8、12……次自然到期可建议长休息，提前结束仍可自主休息。休息可暂停、继续或结束，结束后回专注准备，不自动启动。详见[计时规格](02-features.md#f1)。

### 3.2 想法暂存

“留个标记”立即留下一个可补字的空条目；“记下想法”打开文字输入；“补充文字”只编辑指定条目。每条最多500个Unicode码点，草稿与正式条目分开，明确“保存想法”才成为正式内容；关闭编辑保留可恢复草稿，续写由用户主动打开。

活动专注中，新想法归属编辑开始时的原段；准备、专注结果或休息中创建的想法独立存在。后来到期或开始新段不改归属。已有草稿再另写时，先保存旧稿、明确放弃或返回，不能直接覆盖。

想法可编辑、收起、放回待看、删除及撤销删除；收起不表示任务完成，也不从全部想法消失。删除成功后未满10分钟可撤销；删除想法不改计时和故事。保存失败或旧回执晚到时保护当前文字。详见[想法规格](02-features.md#f2)。

### 3.3 伙伴生活与场景积累

每次专注可绑定一件伙伴自己想做的小事，如清桌、照料多肉或读书。短时长缩小事情范围，长时长增加安静停留；到期前结果应已能看懂。暂停保留本段落点，继续时恢复；提前结束留下短章小记，自然到期留下完整章页。结束后不建立未完事项或跨段进度，不能用未制作内容补造结果。

长期积累落在**同一间逐渐丰富的小屋**。初始空间已经适合生活，已有家具和多肉不包装成新奖励。只有本段自然到期、故事完整走完且结果保存成功，才按章稿收集；1分钟等短段完整走完也适用，不要求固定25分钟。未完整走完仍保留计时与短章小记，不进入收集。完整故事可改变既有物件、留下一件新物件，或只留下可回看的章页；不保证每次添物，不因重复或缺席复制、收回或损坏已有收集。

在记录页“生活场景”看当前小屋。白天／夜晚只换光线和背景，共用同一物件状态。承载生活经历或明确设计为互动对象的物件，提供伙伴小话及可达入口；普通装饰不默认可点。点击互动对象先读一两句小话，再按需“查看来由”或打开原记录；“查看物件／回看故事”提供明确列表路径，未收集的小记也可从回看故事找到。小话来自预写内容，不读取私人想法，不形成聊天或领奖流程。详见[故事规则](02-features.md#story-rewards)与[小屋交互](02-features.md#records-scenes)。

### 3.4 鼓励与收藏

点“给我一句鼓励”直接阅读一句支持；“换一句”沿当前类型换句，“换一种鼓励”在同层选择类型，“收到鼓励了”关闭阅读。当前类别只影响本次请求，不作为用户情绪档案；主动阅读不会被自动话语顶掉。

喜欢的句子可以收藏与取消收藏，保存点击时的句子和文本版本。欢迎笺只支持阅读与关闭；每次故事与小屋物件已有自己的保留方式，不混成可取消的句子收藏。自动节点鼓励可关闭，主动入口仍可用。功能反馈只说明可靠结果，情绪支持只回应本次主动表达。详见[鼓励规格](02-features.md#feedback)。

### 3.5 记录与查找

记录页先选要找什么，再显示对应工具和内容；首屏不放大幅氛围头图。四种方式始终可见，底部仍是原主导航。

| 查看方式 | 主要内容与查找路径 |
| --- | --- |
| 全部记录 | 按日回顾专注与独立想法；紧凑显示近7／30天累计计时与已结束段数，统计详情默认折叠；支持年份／月份查找 |
| 只看想法 | 直接读正式文字和空标记，包含已收起内容；支持月份与文字搜索，另有继续草稿入口；不显示计时汇总 |
| 生活场景 | 看综合小屋、物件小话和真实来由，回看包括未新增物件的故事片段；不受近期统计范围过滤 |
| 我的收藏 | 重读主动收藏句子、欢迎笺及实际已交付内容；按内容性质分组，不显示未来解锁空位 |

列表采用每页最多20条的“上一页／下一页”和页码，翻页替换列表；月份或搜索改变后回第1页，关闭详情回原条件、原页和原位置。搜索覆盖符合月份条件的全部有效正式想法，不限已加载内容。日期工具与小屋大场景分开，选择过去月份不表示还原过去的小屋。

近期汇总范围、列表月份、搜索条件各自可辨。汇总只计已确认保存的已结束专注，不把活动段、休息、草稿或待保存结果混入；未知不当零。编辑想法不改创建日和原排序，当前小屋与当次故事快照分开读取。详见[记录规格](02-features.md#f3)与[指标口径](04-data.md#record-metrics)。

### 3.6 设置与数据管理

设置按常用偏好、数据管理、应用说明分组。默认时长只影响之后的准备与启动；恢复默认时长只重置25／5／15分钟和单次时长记忆。声音默认关闭，试听不模拟到期；系统或应用任一要求减少动态就用静态，关闭场景仍能完成核心操作。

核心资源准备完成后可离线计时、记录、阅读和保存，重新打开恢复已保存数据。支持完整JSON备份与替换恢复；选文件只预览，明确确认后才替换。替换或清空前保护活动会话、草稿和待保存结果，不擅自结束或丢弃；导出不暂停本机计时。已存活动段从备份恢复为暂停，等待用户继续。详见[设置](02-features.md#settings)与[备份恢复](04-data.md#backup)。

## 四、全局约束

| 必须守住的体验 | 执行要求 |
| --- | --- |
| 布局稳定 | 相同视口与字号下，计时外框、主控、常用入口和导航保持稳定；普通对话、成功、错误和等待使用预留位置，不增高背景页。主动展开或翻页按内容规则处理 |
| 内容互不遮挡 | 文字不遮人物面部和关键动作，场景不遮读数或按钮。长文进入可关闭阅读区，一次一层；空间不足先缩装饰，再让当前内容滚动 |
| 操作明确 | 主次动作按任务分组，结束与暂停／继续同组，想法工具另组；名称统一使用定稿词表。点击只执行命名动作，不藏启动、删除或领取 |
| 小屏与辅助操作可用 | 独立触区至少44×44 CSS像素；320宽度和200%文字下内容可达。键盘、读屏和触摸表达相同动作；普通反馈不抢焦点，关闭回来源 |
| 反馈可信 | 区分草稿与正式内容、发生与保存、失败与结果未知；反馈对应具体对象，重试不重复记账。局部问题只限制受影响动作，未交输入受保护 |
| 保存与恢复可靠 | 一份权威记录供各页面读取；断网、重开、并发和替换不能重复结束、错归属或用旧结果覆盖新内容。旧数据未知保留未知，无法安全解释时保护原件 |
| 陪伴低负担 | 真实计时和保存不等动画；输入、确认和阅读优先。关闭动态或场景不影响事实，后台错过的表演不排队补播 |
| 画法统一 | 最终按B.4.1的写意水墨方向验收；当前原型保留既有画法，分别记证据。主角蓝突出、空间接触可信、面部与计时操作清楚，是两阶段共同约束 |

具体尺寸仍待界面稿确认，按同一套参数适配各状态；不从旧图猜定宽高。UI数值、文字寿命、焦点与绘画细则见[全局界面规格](03-ui.md#focus-layout)。数据只约定逻辑格式、含义、关联与结果，数据库、框架和物理组织由开发确定，见[数据契约](04-data.md#data-format-contract)。

| 批次 | 必须交付什么 | 成立条件 |

| 角色定稿与界面尺寸 | 伙伴关系、最终水墨方向、按钮名称和分组已定；当前原型保留现有画法，不能混作最终验收。前三项主性格与轻微笨拙已获用户确认，性格简历见E.11；具体偏好、桥段与表现用样稿校准，具体造型、尺寸和响应式构图用样稿与真机确认 |
| 收集是否有压力、熟悉后是否仍有趣 | 短章小记／完整章页及完整走完才收集已定；不设计跨段未完事项。观察是否诱导拖延休息、反复开短段刷内容或形成补完义务；先调整呈现与内容，不把未收集称为失败 |
| 首个新增物件 | 选择一个自然留下实物的章节，交付可信来源节点和前后构图，不预置为用户已获得 |
| 实际存储与兼容 | 开发确定实现方案，提供逻辑映射、旧数据样本、离线资源和恢复证据；具体方案不能改变既定数据含义 |

### 5.3 怎样判断产品成立

用户无需讲解就能开始、暂停、结束并理解结果；写想法时到期仍保住文字和归属；数月后能找回内容与来由；忽略故事、提前停下或隔月回来均无压力。断网、重开、保存失败、并发、导入及清空下，状态真实、数据不重复或误覆盖；小屏、大字、键盘与关闭动态仍可用。完整用例见[验收规格](07-acceptance.md#acceptance)，通过记录须注明构建、设备、步骤和观察结果。
