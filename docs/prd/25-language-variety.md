## 研究怎样回到产品

| 已有方向 | 当前规格／实现入口 | 仍需要什么证据 |
| --- | --- | --- |
| 至少200条真实可用素材，重点投入开始专注与休息 | [语气规则](08-voice.md)、[使用场景](21-language-scenes.md)、[当前句库](09-encouragement.md) | 260句尚是工作稿；容量达到不等于编辑质量通过 |
| 普通回应、具体偏好、短故事与较长阅读共存 | [创作经验手册](../learning/companion-language/05-writing-playbook.md) | 按真实入口合读，核对是否有新意思、自然、耐看 |
| 关心有依据，角色有自己的内容 | [已确认性格](10-character.md)、[人物框架](20-character-framework.md) | 不推断未表达的心理；不能把咨询示范的提问链搬成开始步骤 |
| 每次打开直接随机 | [当前选句规则](08-voice.md#language-selection) | 不改回轮播／洗牌袋；检查合法池、重复与可见性 |
| 素材丰富，专注过程安静 | [Focus退让](02-features.md#focus-step-aside)、[认知可及性来源](../learning/companion-language/01-foundations.md) | 长话需既有全文入口；不为展示素材增加中途插话 |
