### A.1 计时、暂停与休息

<a id="rule-start"></a>

**RULE-START · 选择与确认。** 选择时长只改本次准备值。只有明确确认开始，才捕获当时所见的合法目标、模式、开始时区及可选小步骤，建立一个会话。开始专注时记一次参与，按[故事规则](#story-rewards)绑定可用章节。沿用默认时长可直接确认。用户试选、改选、取消或未开始即离开，均不创建会话、参与或章节。重复提交只接受一次，启动请求被拒时保留准备值和输入。输入法选字、输入框回车、收起键盘与选值动作都不提交开始，键盘或读屏明确激活开始控件才可启动。

<a id="rule-duration"></a>

**RULE-DURATION · 取值顺序。** 准备专注时依次取本次访问在本模式明确选择的值、最近一次明确选择并成功开始的专注时长、设置的默认值。离开到别的页面再回来保留本次选择；冷重开只读已生效的记忆和偏好。默认专注值真实改变或用户明确重置时长时，清除旧单次记忆及该次动作之前的准备选择；只是打开、失焦或提交相同值不执行清除。迟到回执不清掉之后新作的明确选择，也不改变已开始的目标。只修改休息时长或声音不影响专注记忆。启动后目标锁定；已开始的会话使用自己的时长。

**首版参数。** 默认专注25分钟、短休息5分钟、长休息15分钟。自定义专注1—120分钟、短休息1—60分钟、长休息1—90分钟，取整数。小步骤可空，上限80个 Unicode 码点。非法输入保留可编辑草稿，不覆盖最近有效值。

<a id="rule-pause"></a>

**RULE-PAUSE · 同一会话。** 暂停立即停表，保留剩余量和已达落点，次数不限。继续仅恢复这一个会话。打开便签、切页、锁屏、关页均不隐含暂停、继续或结束。

<a id="rule-end"></a>

**RULE-END · 唯一结束。** 请求手动结束只进入确认。运行段在确认期间照常走，暂停段继续停。取消回到当时有效状态。执行确认或任何会话操作前核对目标会话和截止点：到期优先，按目标时长结算一次；截止前确认才按实际投入结算。有效时间夹在0与目标之间，0秒可留真实开始与结束记录。另一窗口已新开会话时，不把旧确认施加给新段。下一段等待用户自行开始。 同一已受理但待保存的逻辑操作重试按[C.4.1](04-data.md#command-db-contract)保留原受控时刻与会话依据；版本已变则处理冲突，不将重试当作新的确认，也不覆盖已存终态。

<a id="rule-rest"></a>

**RULE-REST · 自主休息。** 随时可以休息。在活动专注中先结束原段，再明确开始休息。准备中选休息类型只改准备值。建议的休息时长须可见，接受建议才开始。每逢第4、8、12……次自然到期的专注，当次结果可建议长休息；走完5分钟与走完25分钟各计一次。手动结束不增加完整次数，不重复触发上次建议。休息暂停可继续，结束或跳过后回到专注准备态。

休息插曲只表达当前休息，不推进专注章、生成专注章页或改变持久生活事实；已有生活仍可作为背景。休息不承担补看剧情或领取奖励的任务。

**功能验收。** 先选5、改15，两次选择均产生零条业务记录。确认后恰有一个15分钟会话和一次参与。运行8分钟、暂停3分钟、继续2分钟后确认结束，记录10分钟、零次完整到期。对应 [T-CORE01—07](07-acceptance.md#test-core) 和 [T-EN01—05](07-acceptance.md#entry-tests)。

#### A.1.1 专注页：模块、状态与功能边界

本节先回答“每块做什么、此刻突出什么、哪些动作成立”，控件分组见A.1.2。**画面由会话状态、当前临时任务、数据状态和屏幕条件共同决定**，不为每种组合新建一页，也不用一个“成功／失败”控制整页。

<a id="focus-modules"></a>

##### A.1.1.1 模块职责与稳定关系

| 模块 | 用户用途与入口 | 可变化内容 | 必须稳定的关系 |
| --- | --- | --- | --- |
| 页面导航 | 去专注、记录或设置 | 当前页面、选中状态 | 导航与返回方式清楚；切页不改会话 |
| 状态与时间 | 看懂准备、运行、暂停或结束 | 模式、剩余／实际时间、当前状态 | 同一计时外框；状态不只靠颜色，剩余与实际时间明确区分 |
| 本次准备 | 选择模式、时长，可选填小步骤 | 准备值、校验与选择状态 | 与开始动作相邻；不改设置默认值，不代替确认开始 |
| 计时控制 | 开始、暂停、继续、结束与下一步 | 主次动作随真实状态替换 | 暂停／继续与结束同组，主控位置稳定；结束可辨可达，不混入想法工具；一次激活只执行原意图 |
| 想法暂存 | 新写、留记号、补指定条目或续草稿 | 指定内容、草稿和保存结果 | 对象与归属明确；不自动暂停，不把补字变成新建 |
| 陪伴与主动鼓励 | 看伙伴生活、轻触或主动请求支持 | 当前姿态、所读句子 | 场景占剩余空间；文字与面部／关键动作互不遮挡；短回应与主动阅读分开，鼓励与轻触不兼任计时／设置入口 |
| 结果与数据反馈 | 判断本段发生什么、哪项已存或需处理 | 实际结果、保存／读取状态和恢复动作 | 结果原位承接，不长出结算卡推走主控；错误归属具体对象 |
| 临时任务面板 | 调时、输入、阅读或确认一次任务 | 当前任务、键盘、内部滚动 | 最多一层；标题、对象、退出可辨；关闭回来源或当前有效位置 |

功能可以共用视觉区域。例如时间区承接结束结果，主控区承接下一步；结果反馈可位于相关模块内，不要求八张卡片。准备项不适用时退出交互，预留空间按同视口构图管理，不能保留隐形热区。固定的是核心锚点与容器边界，具体尺寸见[B.1.2](03-ui.md#ui-size-contract)。

<a id="focus-step-aside"></a>

**计时中卡片让位（用户决定，2026-11-09）。** 伙伴在iPhone和iPad上占据全屏，操作需要时再呼出。准备、暂停、结束和保存问题时，控制卡片、导航和设置入口照常显示，用户一打开就能看懂这是什么。专注或休息运行约4秒后，若无操作，卡片、底部导航、页面标题和设置入口让位，只留房间、伙伴、时间和卡片露出的顶边（带一道抓手，即把手）；点把手或房间空白处，同一张卡片回到原位，约8秒无操作后再次让位。摸伙伴只是摸伙伴，不呼出控件。手指按住、键盘焦点在内、面板打开、短暂提示显示或出现错误时卡片留下；标记的撤销随卡片保留，呼出即可使用。前3段在把手旁说明用途，依据现有参与次数，不新增数据。让位只影响呈现，不改变计时、保存和记录。

竖屏时，卡片让位后房间与伙伴略微靠近，避免留下空地；手或手持物靠近屏幕边缘的场景只下沉、不放大，不裁切手和手持物。**时间与伙伴成为一组（用户决定，2026-11-12）：** 竖屏、非大字布局下，状态词、时间和小步骤在所有状态都排在伙伴头顶上方，只隔一个两行气泡的位置，不再留在屏幕顶端、与伙伴之间空出一大片；页面标题和设置入口仍在顶部。卡片在屏幕上时伙伴站在卡片上方，只有时间这一组下移；卡片让位后，多出的高度约六成留给时间上方的天空、四成留给伙伴脚下的地面，整组略高于屏幕正中，时间与伙伴用同一条曲线一起到位，位置只差少许。没有多余高度的小屏不移动。让位期间不显示小步骤；抽屉打开时时间不动，伙伴上移时不得碰到时间。高度不低于600 CSS像素的横屏，房间铺满全屏，卡片浮在右下；卡片在屏幕上时场景左移，不遮挡手和手持物，卡片让位后伙伴回到屏幕中央。较矮的横屏和大字布局保持原有排布，卡片不让位。

##### A.1.1.2 基础状态与视觉重点

“主动作”是当前最容易辨认的动作，不要求所有状态都放大按钮。运行时读数优先于装饰；正在输入、确认或处理错误时，当前任务优先于背景表演，简短计时状态仍可见。

| 基础状态 | 第一视觉重点 | 主动作与必要次操作 |
| --- | --- | --- |
| 恢复中 | 正在恢复的真实状态；未知时间用占位 | 等待或处理已确认的问题，不先闪出可开始的25:00 |
| 准备专注 | 本次所选时长、明确的开始入口 | 开始专注；选时长、选休息及可选小步骤 |
| 专注运行 | 正在计时、剩余多久 | 暂停专注；结束专注、想法入口可达 |
| 专注暂停 | 已暂停、时间停止、保留的剩余量 | 继续专注；结束专注、想法入口可达 |
| 专注结束 | 本次实际计时与单独的保存状态 | 开始休息（旁示时长）或准备专注；不自动执行任何一个 |
| 准备休息 | 休息类型、时长及尚未开始的状态 | 开始休息；调时长、返回专注（仅回准备） |
| 休息运行 | 当前在休息、剩余多久 | 暂停休息；结束休息并回到专注准备 |
| 休息暂停 | 休息计时已暂停 | 继续休息；结束休息并回到专注准备 |
| 休息结束 | 休息已结束，下一段尚未开始 | 按A.1回专注准备，固定状态位交代结束；不另设必须停留的结果页 |

**数据异常是叠加条件，不是第十种计时状态。** 准备、运行或结果上都可能出现待存、失败、未知、只读或仅本次可用。保留可信时间和状态，就近说明受影响对象；可用动作依[C.5](04-data.md#saves)限制，不能把记录失败画成仍在运行，也不能因读失败显示零记录。

##### A.1.1.3 各状态允许做什么

下表只说明业务可用范围；实际执行还需通过数据可用性、来源对象及在途操作检查。模态打开时背景不可操作，关闭或按B.3安全切换后再执行其他任务。

| 功能 | 无活动会话的准备态 | 活动专注（运行／暂停） | 专注结果 | 活动休息（运行／暂停） |
| --- | --- | --- | --- | --- |
| 模式、目标时长 | 可改对应准备值 | 本段锁定；不提供伪装成普通切换的“去休息” | 点“准备专注”后修改；开始休息需明确时长 | 本段锁定；结束后回准备再选 |
| 当前小步骤 | 专注准备可填、可跳过 | 按开始时快照展示，不编辑本段 | 展示原段；下一段另填 | 不改旧专注的小步骤 |
| 新想法／新记号 | 独立条目 | 关联编辑开始／点击时的本段 | 通用新建为独立条目 | 独立条目 |
| 补指定条目／继续草稿 | 保持原对象和归属 | 保持原对象和归属 | 回看或编辑指定条目，不重新归属 | 保持原对象和归属 |
| 主动鼓励／轻触 | 可用 | 可用 | 可用 | 可用 |
| 导航／设置 | 可用 | 可用，计时不变 | 可用，按A.1.1.4返回 | 可用，计时不变 |

休息已结束按专注准备列处理；只读时可阅读已存内容，写入相关动作另依C.5。现有草稿不因当前会话改变就自动挂到新段。没有新动作或需要处理的状态时保持安静，不追加提醒。

##### A.1.1.4 首次进入、结果退出与重返

**首版构图基线。** 蓝色伙伴坐在窗边，杯子、合着的书和莲座多肉在柔和侧光里。本地数据可用后才显示准备时间：首次25:00。点击时间数字或旁边铅笔打开1—120分钟刻度尺，亦可直接输入整数分钟；“用这个时长”只准备，“开始专注”才启动。取消不改变已生效准备值；按住开始按钮不承担调时功能，不再保留5／15／25快捷按钮行。“开始专注”与读数相邻，嵌在稳定承托面。小步骤与欢迎语不挡操作，用户不必选故事。具体画法按B.4.1，尺寸随界面稿确认；18:42仅为运行示意。

专注结束后在原时间／主控区域显示结果；没有操作就保持，不倒数催促、不重播鼓励。选择“准备专注”才回准备，之后明确开始才建立新会话；选择“开始休息”才开始可见时长的独立休息。未保存的原结果依C.5继续保留，不能随结果画面退出而丢失。

本次访问切到记录或设置再回来，若没有进入新的准备或会话，仍显示原结果；已进入准备就保留当前准备上下文。冷启动按[C.6](04-data.md#recovery)：已结算的旧段从记录回看，恢复中刚发现到期则展示本次核对出的结果。休息结束或跳过回专注准备，不恢复旧专注、不补播收尾。新会话成立后以新会话为准；编辑／阅读面板仍按原来源处理，不被结果强制关闭。

规则完整性用[连续路径](07-acceptance.md#focus-journeys)验证，模块之间如何一起变化见[A.1.3](#focus-linkage)。

#### A.1.2 计时控制组与结束确认

**卡片两行（用户确认，2026-11-12）。** 卡片只有两行：计时控制组一行；其下一行是三个等宽工具——“给我一句鼓励”“留个标记”“记下想法”，图标在上、文字在下，靠间距与控制组分开。本段想法数量入口固定占这一行的第四格，有无想法都不挪动前三个工具。阅读鼓励时“给我一句鼓励”留在原位并呈按下状态，再点一次即收起。运行与暂停时，状态词旁写出本段目标（如“已暂停 · 目标 25 分钟”），卡片内不再重复状态行，读屏仍读到完整状态；专注结果和准备休息时，卡片上方多一行结果或休息类型与休息时长选择。小步骤归到时间下方：准备时是一枚可点的小胶囊，计时中是一行文字，大字布局仍在卡片里按阅读顺序排列。主按钮在所有状态使用同一主蓝色，暂停、休息与结束由状态词和按钮文字区分，不靠换颜色。

**计时控制组定稿。** 时间下方同组展示主按钮和结束按钮：运行时为“暂停专注／暂停休息”，暂停时为“继续专注／继续休息”；次级按钮分别固定为“结束专注／结束休息”。结束按钮紧邻主控，可采用同排或紧接下一行，但在相同屏幕条件下保持固定位置；不得与“留个标记”“记下想法”混成一排小链接。鼓励与想法工具在计时控制组之外另成一行，与其有清楚间距或容器区别。次级按钮有可辨边界，触区和对比按B.1，不使用警告红色暗示结束是失败。

“结束专注”只打开确认：标题为“结束本次专注？”，说明为“本次将按实际计时时长记录。”，操作为“返回计时／确认结束”。确认从“结束专注”按钮处升起并指向它，背景变暗且不可操作，房间与伙伴保持原大小；按钮上方放不下时（大字、较矮的横屏）改在屏幕中间显示，并附一行简短计时状态。两个选项同样大小：“确认结束”为浅蓝，“返回计时”为中性，都不使用警告色；点背景、Esc或系统返回等同“返回计时”。确认不是已保存，结果仍依C.5。运行期间打开确认不暂停，返回时原本暂停仍暂停。“结束休息”按现有规则结束休息并回专注准备，不新增确认步骤、不自动开始专注。按下到抬起状态改变时取消旧激活。

详细状态见[A.1.1](#focus-entry)，每个动作的表现查[ACT-A](13-actions.md#act-a)／[ACT-B](13-actions.md#act-b)；准备时长、想法归属及结束条件分别依[A.1](#f1)、[A.2](#f2)。名称唯一维护于[B.6](03-ui.md#ui-copy-catalog)，此处说明分组与行为。

#### A.1.3 专注页：一次变化影响哪些模块

本表描述A.1.1模块之间的联动，不重复定义写入规则。**受影响模块读取同一事实；未涉及的输入、归属、阅读和位置不随之重置。** 发生不等于已保存，界面可以即时反映已受理的状态，但须独立保留准确的写入状态。

| 触发 | 一起更新什么 | 保留什么／冲突时怎样处理 |
| --- | --- | --- |
| 选模式、时长或改小步骤 | 准备值、选择状态、主动作所说明的对象／时长 | 不启动、不改默认、不生成章节；取消回原有效值 |
| 开始专注或休息 | 时间、模式状态、主次控件、合法场景姿态 | 主控原位，约4秒后随卡片[让位](#focus-step-aside)，呼出时仍在原位；不自动打开输入或追加说明区；启动失败保留准备值 |
| 暂停／继续 | 时间运行状态、状态词、对应按钮、场景动作 | 原会话、草稿和已达内容不变；旧回执不把新状态改回去 |
| 留记号或保存想法 | 对应条目、保存状态、该对象的补字／撤销及相关读取 | 不动计时；连续两个记号的操作分别指明对象；撤销不用“最近一条”猜目标 |
| 打开、关闭或切换面板 | 当前任务、输入／阅读焦点与内部滚动 | 背景位置不动；退出按来源返回；换任务先依B.3保护草稿 |
| 请求鼓励、换句或收藏 | 当前句子及其收藏状态；错误归对应操作 | 计时、输入和所得不变；自动回应不能顶掉主动所读内容 |
| 请求结束、取消确认 | 当前确认任务及有效控件 | 原运行／暂停照常；不先演结束，不新建业务结果 |
| 确认结束或自然到期 | 原段终态、实际计时、保存状态、下一步控件与当前场景 | 正在写的文字／键盘／焦点及原归属保持；过期确认失效；只结算一次 |
| 写入失败、重试或结果未知 | 原对象的状态、恢复入口及必要的局部可用性 | 已存数据仍是已存；不遮主动阅读，不清待存副本；未知先核对 |
| 切页、后台重返或另一窗口变更 | 当前页面及最新可信会话、条目和可用动作 | 不暂停或重播；旧按钮不操作新段，旧输入不改挂新对象 |
| 键盘、大字、横屏、减少动态或更新提示 | 按B.1调整当前容器、焦点或静态表达 | 视口条件变化与普通状态变化分开验收；更新不强制重载，装饰不改业务 |

只需要为有视觉差异的组合补状态稿；其他组合在相同规则下验证。每个实际交付模块登记“职责与入口 → 可用状态 → 关联变化 → 固定边界 → 退出与异常 → 用例”，复用本章、F和D，不再维护第二套动作清单。

### A.2 想法暂存与返回

**想法暂存不计分、不发奖，也不催办。** 记录行为不额外推进故事，计时仍按原状态运行；便签内容不用于选章或改写剧情。未处理的想法不转成逾期事项、红点催办或清空任务；休息与下一段不以处理便签为前提。

<a id="rule-note"></a>

**RULE-NOTE · 入口决定归属。** 记号表示“此刻有件事想先留个位置，可以以后补字”，不是已确认的分心、打断或情绪事件，不据此推断注意力。一触留记号立即提交一条空标记。写独立新想法与给指定记号补文字是不同意图。专注运行或暂停时，新想法归编辑开始时所见的会话；没有活动专注时（含准备、专注结果及休息），从通用入口新建的想法或记号默认独立；活动专注中的新记号绑定点击时的会话。若从历史或指定条目进入，绑定所选目标。首次非空输入确定新草稿的创建时刻和日期，后续补字沿用原条目的身份与创建日期。编辑期间到期或另一窗口开始新段，归属不变。

<a id="rule-draft"></a>

**RULE-DRAFT · 从草稿到正式条目。** 一个数据世代保留一份可恢复的草稿。关闭编辑按草稿保留，主动续写才重新打开键盘。只有明确保存才生成或更新正式文字条目。新草稿去掉首尾空白后为空时不可保存；清空有正文的既有条目时提示结果，确认后留下原ID的空记号。每条想法上限500个 Unicode 码点；组合字符按码点计，输入、粘贴、提交、读屏使用同一口径。超限保留可修改文字，旧数据不静默截断。若已有草稿又要另写，允许先保存、明确放弃或返回。草稿或原件并发变化时按[C.5](04-data.md#saves)处理。

**空值提交与草稿寿命。** 判空统一依[C.9.3.0](05-data-fields.md#database-field-contract)的固定字符集合，只判断是否全空白，不裁剪有效正文。已有正文清成空记号须确认；原本就是空记号且没有净变化时，不重复要求清空确认。打开新输入器只绑定本次来源，首次实际输入后才创建需持久保护的新稿；创建、更新、提交、明确放弃是不同命令。草稿槽位相同不代表同一草稿，必须匹配draft_id及版本。原稿提交/放弃后，旧create/update不得用新操作ID复活该寿命；恢复同一已存草稿则沿原身份。

<a id="rule-undo"></a>

**RULE-UNDO · 撤销有明确对象。** 刚留记号后的撤销只删除该次标记。明确执行便签的「收起／放回待看」只改变该条目的待看状态，不表示现实事项完成；阅读、关闭编辑区或折叠记录不执行该动作。删除与撤销指向同条目、同删除版本和同数据世代。删除成功起未满10分钟可撤销，正好10分钟失效；过期释放暂留正文、保留必要删除标识。删除便签不影响所属专注、投入和故事。一次手势、长按重复事件或重试沿用原操作身份。首版同窗口同入口同归属的空标记，在首次接受后的800毫秒内合并，满800毫秒后再次主动点击可留新标记；不同窗口的独立意图不因时间接近而合并。

**结束结果中的入口。** “本段想法”用于回看该段已有内容；通用“记下想法”用于新建，两者不共用含糊的“记录”。编辑期间会话结束仍保留原归属；从结束结果重新打开通用新建入口，不自动补记到刚结束的会话。

**眼前输入与正式保存。** 保存以用户确认时的输入快照为对象；该快照尚未可靠落入同一草稿版本时，先保护并提交该快照，不用较早自动保存的文字代替。输入法组合态、换行、收键盘和普通退出不正式提交。提交后又有新字时，原成功只确认原快照，保护后续输入并按最新条目与单草稿槽位承接，不重复新建正式想法。自动保存、放弃与另写的执行次序见[C.4.3](04-data.md#frontend-command-contract)。

**快捷撤销不追赶新版本。** 撤销刚留记号绑定该次创建的ID、版本和世代；标记已补字或被修改，旧快捷撤销失效，不刷新版本后删除新内容。800毫秒局部合并不复用已撤销、已删除或不再是原标记的对象；失败重试与后续新意图分开。正式删除／撤销仍按原规则。

**功能验收。** 在第一个会话内写“晚上取快递”，跨过到期点再保存，正式条目仍只出现在第一段。只打开再关闭时，正式记录数不增加。对应 [T-FQ03—05](07-acceptance.md#focus-journeys) 与[跨模块测试](07-acceptance.md#boundary-tests)。

### A.3 日常章节、过程记录与长期生活

故事遵守[角色关系](01-product.md#relationship)和[世界观](01-product.md#worldview)。每章先有伙伴自己想做的事，再与计时建立联系。**短章小记、完整章页与故事收集分别表达归档事实和收集条件，不划分关爱或用户价值。** 不展示失败、残次、欠一次完成或“就差一点”的评价。

<a id="rule-story"></a>

**RULE-STORY · 一段可讲清。** 每次支持故事的专注绑定一件在所选时长内可讲清的小事；走到目标时，结果须已可辨。短稿缩小事情范围，长稿增加安静停留，不把短稿强行加速成未发生的大事。有效计时驱动本段节点；点击、观看、真实日期均不额外推进。每个落点须有可安心停留或离场的姿态，不制造角色悬着等用户救场的情境；安置道具不补造故事成果。

| 发生的事 | 当次记录 | 收集及下次行为 |
| --- | --- | --- |
| 刚开始或极短暂停 | 保留可信起步位置与本段检查点，0秒不凭空推进 | 不新增收集；原活动会话可以继续 |
| 暂停／继续 | 保存原会话的节点与节点内进展；暂停期间不推进 | 继续恢复原段，不新增实例、不重复记账；尚未到期不收集 |
| 截止前确认结束 | 按已发生过程归档短章小记；已出现成品可以如实记入当次历史 | 本段不进入收集，不写新小屋成果，不生成待续事项；下次独立开始 |
| 自然到期 | 以真实本段结果归档完整章页 | 满足RULE-COLLECT才收集；未制作／结果缺失不能因到期补造完整故事或物件 |

<a id="rule-continuity"></a>

**RULE-CONTINUITY · 原段可继续，结束不留待办。** 暂停、刷新、重开和导入恢复的是同一个未结束会话，必须保留身份、目标、本段故事绑定与合法检查点。手动结束或自然到期后，该实例终止；不创建未完事项、待接续队列或跨时长节点映射。下一段从合法起点独立选章，不把旧段分钟、节点内等待或未收集变化带入新段。故事题材可再次出现，但属于新实例，旧小记不被改写；不要求用户补完先前的故事。

<a id="rule-collect"></a>

**RULE-COLLECT · 完整走完才收集。** 本版“完整走完”指该专注会话自然到期，且所绑定、已交付的故事达到章稿定义的完整结果；相关终态提交成功后才成为已收集。三者缺一不可。计时已自然到期但缺有效故事结果，只保留可信计时与可解释摘要，不补造章页或收集。

- 手动结束即使已看到结尾姿态，仍按短章小记记录，不按“接近目标”或“画面已经演完”提前授予收集。暂停后继续并最终自然到期仍符合条件。
- 完整章页由原会话保存；收集的物件或生活变化按章稿明确条件进入当前小屋，同一对象不重复发放。不要求每章新增物件，不增设领取动作、图鉴空位或收集进度条。
- 本段的中间变化只属于本段检查点和历史；尚未收集时，小屋继续读取原有初始／已收集状态，不提前出现待领取物件。前台故事与小屋可以处于不同的呈现阶段，不将本段画面宣称为永久获得。
- 短章小记、计时与想法仍完整保存和可回看；“我的收藏”中的主动句子收藏不受故事完整条件限制。缺席不撤销既有收集，旧版本已可靠取得的成果也不按新规则追溯扣除。

<a id="rule-select"></a>

**RULE-SELECT · 开始时选择，段内不重派。** 无活动段时显示当前生活背景。确认开始后，过滤未制作／不可用、前情不合及不适配本次时长的稿件。新段无待续事项；前情只读取初始事实、已收集成果和已明确兼容的旧事实。未收集的一次尝试不能解锁后继，也不因此锁住所有活动。首次进入按已编写顺序选合法初始事件；已有尝试后，在合法未收集事件与重复日常中按稳定目录轮换，不强制反复派同一未收集事件。存在因果前置的后继仍须等待相应成果真实收集。

重复与再次尝试均创建新实例，内容稿明确其合法入场，不声称“接着上次做到一半”。轮换位置只随成功绑定保存，重试、失败、取消、普通计时和缺席不推进或重置；同一日常内部的变体也按稳定目录轮换，不抽稀有内容。会话绑定身份与版本后，到期、重开、切页、换展示或更新目录均不重派。仅一项可用可以重复，空集回普通计时，不能要求用户改时长。

<a id="content-continuity"></a>

**内容后继与重复。** 每条已交付生活线须有合法后继或至少一项有本次动机、能独立结束的重复日常。已收集的首次事件不重新发放；未收集的尝试允许以后重新开始，历史仍保留原过程。重复不能撤销已收集事实，也不把换色称为新剧情；变体预写，不引入随机事件引擎。正常内容用尽后长期只剩普通计时，不能称为完整陪伴版本。

**记录与积累有不同职责。** 当次历史保存实际过程及归档原因；当前生活保存初始／已收集的事实与布景。未完整走完的小记属于过去的尝试，不建立必须持续维护的半成品世界。已收集的“曾清好桌子”不代表桌面永远不变，后续变化须有完整章稿依据；已读完可以重读，已浇的盆不因缺席自动变干。熟悉小事也能成为完整章页，不增加领取、整理或腾位任务。

**发生不等于观看。** 计时、过程记录与收集资格根据会话及故事事实核对；关闭场景、减少动态、错过表演、后台到期都适用相同规则。不要求盯屏、点击或播放完动画，动画回调不能推进或发放。

**独立生活不等于离线自动推进。** 没有活动会话时，缺席不生成剧情、成果或待补事项；已有运行段仍按[恢复规则](04-data.md#recovery)核对有效时间与截止点。角色的自主性由动机、选择与习惯表达，不靠用户供养。

<a id="living-scene-rule"></a>

**RULE-LIVING-SCENE · 小屋承接已收集的生活。** 初始小屋已经适合生活，伙伴不靠用户获得桌椅、光线或善意。后续完整章稿可以留下新物件、改变既有状态或只有完整章页。收集条件统一按RULE-COLLECT；每段不必增加物件，不要求连续使用或主动领取。

| 变化类型 | 本版规则与内容例子 |
| --- | --- |
| 已有物件变化 | 完整清桌章可留下可用桌面；完整照料章可留下养护痕迹；完整读书章可更新书签。它们不包装成获得新桌、新盆、新书 |
| 新物件留下 | 章稿须真实包含“把照片放进相框并摆好”等完整结果，且本段符合收集条件，才在小屋留下相框。DAY31／DAY25仍为候选，未制作不预置 |
| 部分过程与无新增 | 暂停保留原段；手动结束只留真实短章小记，不产生新收集。完整但无新物件的日常也保留完整章页，不复制物件凑奖励 |
| 重复与保留 | 同一物件稳定身份，后续符合收集条件的故事可改变其现况；缺席或新段不收回已有成果 |

节点检查点只写本段故事。自然到期结算时，将会话终态、故事结果与符合条件的world_state变化原子保存；失败保留待存副本，不声称已收集。当前新增收集的来源必须是符合条件的已结束会话；旧成果有据而来源不明时保留并说明，不伪造新日期。综合场景只汇合适合留在小屋的成果，吃饭或外出不必留下永久饭菜或把猫收养进屋。

**功能验收。** 同一多肉章在“备好壶”与“已浇湿”两处提前结束，历史如实不同，两者均不收集；自然到期且结果可信、提交成功才收集。隐藏场景、暂停后继续、后台到期和重试所得一致；新段不读取两处未完进度。见[故事用例](07-acceptance.md#story-tests)。

#### A.3.1 场景积累与回看入口

<a id="scene-collection-rule"></a>

**RULE-SCENE-COLLECTION · 用一幅综合场景承接积累。** 首版只有一个综合生活空间，工作名“窗边的小屋”，记录页入口定为“生活场景”。清桌、读书、照料植物等日常共享这一空间，白天和夜晚是同一空间的两种呈现。收集感来自小屋慢慢出现有来由的物件和变化，不按每个题材创建一张主场景卡，不把每次计时等同于获得一个新物件。

| 用户看到的内容 | 真实依据与边界 |
| --- | --- |
| 小屋当前全貌 | 初始布景＋已确认收集的生活事实与合法布景；不把默认家具、当前段过程或未收集小记算作新获得 |
| 物件及痕迹的来由 | 目录将物件关联到符合RULE-COLLECT的原会话终态；从物件入口读来由。初始布景与可信旧来源单独说明 |
| 每次故事片段 | 仍由原会话保留真实落点；提前结束、没有新物件的日常也能从“回看故事”找到，不为完整画面补造结果 |
| 旧版或缺素材内容 | 保留可信文字与原记录，无法确认物件归属时进入“旧故事片段”，不猜物件、日期或新成果 |

物件逐步留下的条件在[A.3](#living-scene-rule)统一定义。点击明确的互动对象先展示伙伴关于它的一两句小话；可进一步查看来由，交互见[A.3.2](#object-talk-flow)，文案见[E.10](11-dialogue.md#object-talk-copy)。这里是回顾与查看入口，不创建第二份历史、物件背包、可取消的收藏关系或解锁积分；阅读、昼夜切换和点击物件不发奖、不启动专注、不改角色生活。场景与物件映射见[C.9.6.1](05-data-fields.md#record-read-contract)，页面见[A.3.2](#records-scenes)。

#### A.3.2 生活场景：同一间慢慢丰富的小屋

入口定为“生活场景”，页面标题使用工作名“窗边的小屋”。主体是一幅有固定构图的综合生活画面；初始就能看见完整可住的小屋，后来慢慢增加物件或生活痕迹。清桌、读书、照料植物属于小屋中的生活，不各占一张主场景卡。小屋现在怎样与某次故事当时怎样分别读取，规则见[A.3.1](#scene-collection-rule)、[A.3](#living-scene-rule)。

| 模块 | 默认呈现与交互 |
| --- | --- |
| 综合小屋 | 一张完整画面承接窗台、小桌、墙面／置物架等固定区域；初始家具与已有多肉照常存在。已确认收集的变化按预设位置表达，不先画满未来收藏物，也不显示带锁空槽 |
| 昼夜选择 | 图外固定“白天／夜晚”两项；只换窗外、环境光与必要灯光层。物件、位置、来由与持有事实一致，不算两套场景或两份收藏 |
| 物件小话 | 点击明确的互动对象，先在画面外固定区显示名称与一两句小话，再按需“查看来由”；选定的初始物件也可互动，不要求先收集 |
| 查看物件 | 图外明确按钮，按画面区域列出互动对象及全部已收集物件；区分“初始布景”与可信来由。列表与画面入口指向同一对象，纯装饰不自动列为按钮 |
| 物件详情 | 名称、当前已收集状态及真实来由；同一物件的相关完整经历按日期倒序，每页20条，可点“查看这次记录”。旧来源未知如实说明，不将当前未结束会话列为新收集来源 |
| 回看故事 | 直接列全部可读故事片段，每页20条，可按原记录月份规则查找；没有新增物件的短段也可找到。不能可靠归属物件的旧内容另有“旧故事片段”入口 |
| 返回 | 物件／故事详情“返回小屋”；打开原记录后“返回场景”，回原物件或故事条目，再回小屋。保留对应位置，不改变全部记录原条件 |

<a id="object-talk-flow"></a>

**点击物件的完整流程。** 承载已收集生活经历或明确设计为互动对象的物件须有小话和可达入口；普通装饰、墙面、地板、环境光不默认可交互。互动对象有名称、可辨提示、可访问按钮语义和选中反馈。画面触区不足时提供图外同名入口，不缩小命中范围或叠出不可区分的热点；全部已收集物件仍可逐项从列表找到。

1. 点击物件或选择对应列表项，显示该物件名称和伙伴小话，正文1—2个短句，通常不超过40个汉字。只显示一个物件的回应，不自动跳到历史详情、开键盘或暂停计时。
2. “查看来由”进入该物件的状态与相关经历；初始物件说明“初始布景”，不编获得记录。“收起这段话”只清当前选择和小话，回原小屋，不取消任何已有物件。
3. 点另一个物件原位替换；连续点当前物件不叠层、不排队、不重抽。每个物件／状态可配置1—3条预写短句，收起后再次主动点击才按顺序换下一条；游标只在当前访问保留，没有永久已读进度或未读红点。
4. 昼夜切换保留当前物件与小话；首版小话不依赖时段，避免夜景显示“太阳刚出来”等错配。物件真实状态变动或切到另一数据世代时重新核对文案条件；旧响应不得把前一个物件的话塞给新物件。

**位置与注意力。** 画面下方预留固定的物件小话区域，未选择时显示轻量提示，出现／换句／收起不增高页面、不盖住角色面部或物件。当前视口与字号下按合法最长文案留空间；普通手机字号应能同时看见小屋与小话首句。空间不足先缩装饰画面，必要时按LAY-09切到独立阅读布局并提供返回，不缩文字或只露半张脸。离开生活场景关闭本次小话，不跨页延迟播放；返回小屋保留昼夜及原查看位置，小话不自动重开。

小话表达角色自己的生活与趣味，不将每个物件变成对用户的夸奖；不说“你专注得好才有它”、不催继续、不因缺席伤感，不从用户现实任务推测物件经历。文案条件与样例统一见[E.10](11-dialogue.md#object-talk-copy)。

**昼夜默认与时序。** 本次访问首次进入生活场景时，按设备本地时间06:00（含）—18:00显示白天，其他时段显示夜晚；这是首版呈现默认，不是天文日出日落，不取定位。用户可随时切换，本次访问保留最后所看版本，阅读中跨时段不自动抢切，冷启动重新取本地时段。换昼夜不推进故事、不补发物件、不改变计时或首页展示偏好；只需一套构图加两种光线／背景层，不重复制作两套物件状态。

**逐渐增加但保持清楚。** 物件由章稿指定固定区域、占位及可读状态，新物件出现不能遮人物面部、重要动作或查看按钮；昼夜切换、加载图片与保存回执不改变画框高度。减少动态时静态落位即可，不需要弹窗领奖。重复故事主要改变同一物件的使用痕迹，不不断复制同类物件。

每版内容随构图声明可容纳的物件与组合规则；超出容量的新内容必须先交付新构图或明确的同类组合表现，不能自动缩成看不清的小图、挤掉已有物件或让用户腾位。同类可以在书架等固定区域合并表现，但“查看物件”始终可逐项查看已留下内容，每页20条；组合不删除持有事实或历史。首版不做自由拖拽、装修背包、房间升级、买卖和多房间切换。

**当前画面与历史边界。** 小屋显示已确认的当前生活状态；历史记录保留当时光线／物件的可信快照，用户切成夜晚不把早前记录改成夜景。看物件或故事不播放实时剧情、不恢复旧计时；动画回放仍为后续能力。关闭首页场景／减少动态的偏好不因主动查看而被反开，文字列表始终可达。

**首轮内容验证。** 先验证“初始小屋 → 已有物件留下变化 → 一件有来由的新物件加入 → 再回来仍能认出”。现有清桌、多肉、读书三章可验证状态积累，不能将它们伪称为获得三件新家具；实际新增物件须有相应章稿与可信节点。相框、薄荷小盆等仍按[E.12](12-stories.md#chapter-brief)与[5.1](01-product.md#record-delivery)决定制作，概念稿不算用户已获得。

**物件小话与鼓励分开。** 生活场景中的物件小话是角色围绕物件的习惯、观察或已发生的趣事，不评价用户，也不套用主动鼓励分类。使用预写、与物件状态相符的短句；不读取便签、推测情绪或生成聊天。点击只触发这次表达，不推进故事、增加物件或改变收藏。规则见[A.3.2](#object-talk-flow)，样例见[E.10](11-dialogue.md#object-talk-copy)。

### A.4 鼓励与收藏

<a id="rule-support"></a>

**RULE-SUPPORT · 事实优先。** 基本善意与支持不以时长、完成次数、观看或互动作为资格；增加内容不能解锁“更值得被喜欢”的待遇。用户主动要鼓励可得到一句支持、换句或结束阅读。节点鼓励可关闭，主动索取仍可用。手动与到期收尾同等温和。只有实际操作和可靠的保存结果才可触发相应的成功表达；错误优先说明，旧事件不排队补播。主动类别只影响本次请求。鼓励、猫的反应和物件装饰均不读取便签内容、猜测心情或制造依赖。

欢迎笺可忽略、可重读。收藏保存明确选择的句子身份、版本和当时文本；取消收藏只解除该关系。隐藏纪念或关闭场景不改变持有事实和进度。未来独立插画权益须先有审核过的规则和内容，再按资格自动、去重发放，不靠连续使用或最低时长维持。本期故事推进按 RULE-STORY。文案条件及完整文本见[内容资产（附录E）](08-voice.md#encouragement-copy)。

<a id="collection-kinds"></a>

**同区展示，不同操作。** 主动收藏句子可依原规则取消收藏；欢迎笺首版只支持阅读与关闭，不虚构可取消的收藏关系；已获长期内容仅在资格和使用规则均已交付时，提供已支持的选用或展示控制，隐藏不撤销资格。每段故事纪念从所属记录或生活场景的回顾入口访问同一快照，不新增逐段收藏或删除；生活场景独立于“我的收藏”，不把物件随故事留下写成主动收藏。不能给这些对象统一套“取消收藏／删除”，也不因此新建欢迎笺隐藏或权益回收能力。

**收藏绑定点击时的内容。** 捕获句子ID、所显示版本、文本快照及关系修订；换句、切页或关闭不改变已受理对象。A的回执不能把新显示的B标为已收藏。取消后重新收藏仍按同一句子身份处理新的明确意图，快照取再次点击时所见文字，不无故覆盖仍有效收藏。欢迎笺与权益操作不借此增加收藏关系。

**收藏寿命。** 有效收藏重复收藏同一quote_id，不刷新收藏时间、不覆盖已选文本或增加行版本；明确取消后再次收藏，才捕获本次选择的版本、文本和时间。取消保留关系身份与必要版本，正文清空；旧取消回执不作用于后一次收藏。来源文本须与已登记本地句子版本相符，不能把前端任意文本当成已有句库。欢迎笺、已有资格和每段纪念不通过该命令写入。

<a id="response-basis"></a>

**回应依据分开。** 功能反馈只陈述可靠状态；情绪支持只回应用户本次主动表达；角色自身情绪来自它的故事，不诊断用户。计时结束只能说明这一段计时结束，伙伴做成一件事也不代表用户现实任务完成；不得合并成“我们把任务完成了”。未知状态可以中性回应，不把暂停、短段或缺席解释为疲惫或焦虑。深层共情沿用主动入口，不新增情绪采集。详见[内容资产（附录E）](08-voice.md#encouragement-copy)。

<a id="encouragement-flow"></a>

#### A.4.1 主动鼓励：阅读与类型选择

**已定流程。** “给我一句鼓励”直接打开阅读区并给一句“日常鼓励”，不先分类。阅读区包含当前句子、当前类型、“换一句”“收藏这句／取消收藏”“换一种鼓励”和明确的“收到鼓励了”。阅读为主，换句为常用操作，类型选择为次级操作；关闭固定可达。只在保存成功后显示“已收藏”。

| 用户动作 | 同一面板的变化 | 返回与保留 |
| --- | --- | --- |
| 给我一句鼓励 | 进入日常鼓励的句子阅读 | 创建本次阅读上下文；不改计时，不猜用户情绪 |
| 换一种鼓励 | 内容区原位切到“选择鼓励类型”，显示四项及当前选中状态 | 不在原句下追加四按钮，不开第二层；“返回鼓励”可取消选择，“收到鼓励了”可退出 |
| 选择另一类型 | 切回阅读，并显示该类型的一句和当前类型 | 点击选项即生效，不再加确认；只影响本次阅读，不暂停、不自动休息 |
| 选择当前类型／返回鼓励 | 回到原句及原阅读位置 | 不重抽、不推进轮换；需要新句时使用“换一句” |
| 换一句 | 在当前类型中按E.2换一句 | 面板和操作位置保持，原句的收藏回执仍归原句 |
| 收到鼓励了／关闭后再次请求 | 关闭回原入口；重新请求从日常鼓励开始 | 明确关闭后本次类别结束；本次访问内的组件重建／切页恢复沿用既有阅读上下文，不重新抽句；不新增跨冷启动的阅读状态存储 |

四项名称与文案池固定对应：**日常鼓励→ASKG、开始有点难→ASKS、刚被打断→ASKB、有点累了→ASKT**。后三项只在用户本次主动选择后使用相应条件句；不保存为情绪档案或长期默认。原句库内容和编号保持，变更的是入口名称与操作流程。

**空间与退出。** 阅读／选择共用同层外框，先按最长合法内容和选项状态确定当前屏幕下的边界，关闭位置固定；长文在内容区滚动。普通状态气泡不承担该面板，文字和控件不遮面部／关键动作。小屏、大字不足以并置场景时使用独立阅读布局，场景可暂退场，简短计时状态仍可辨，按LAY-04保证内容与返回可达。按键身份改变时取消原激活；选择区的“返回鼓励”回原句，“收到鼓励了”退出整个鼓励，系统返回／Esc在选择态等同“返回鼓励”、在阅读态等同“收到鼓励了”。读取异常或到期不抢当前阅读。

<a id="records-favorites"></a>

#### A.4.2 我的收藏

保留入口名“我的收藏”。主动收藏的鼓励句按收藏时间倒序，每页20条，支持重读和取消收藏；欢迎笺及确已交付的长期内容在有对应内容时分组显示，各按[A.4](#collection-kinds)提供动作。每段故事从生活场景的回顾入口或原记录查看，不自动复制进收藏。没有主动句子时只说明该组为空，不能遮住已有欢迎笺；未启用的权益不显示空壳分组或解锁占位。

<a id="f3"></a>

### A.5 长期记录与回顾

<a id="review-purpose"></a>

#### A.5.1 目标与职责

**记录用于确认已记录的时间、找回暂存的想法，以及重看共同经历与喜欢的内容。** 默认按时间组织经历，同时提供想法、生活场景与收藏的集中查看。不评价用户表现，不要求复盘、整理或持续使用；没有计时记录不代表用户没有做事。

本节只定义用户能回顾什么、能做什么。数据对象、指标及保存依据统一在[数据规格（附录C）](04-data.md#data)维护；页面选择、排序、范围切换和返回策略在[A.5.7](#records-ui)维护。稳定约束与可变策略的分工见[数据规则分层](04-data.md#record-rule-layers)。

<a id="review-objects"></a>
<a id="rule-review"></a>

#### A.5.2 经历与内容入口

**RULE-REVIEW · 同一份历史。** 一次已结束专注是默认回顾单位，可关联本次计时、用户当时填写的小步骤、所属想法和当时故事结果。页面组合已有对象，不复制成另一份可独立修改的历史；具体身份与关系见[数据对象](04-data.md#data-objects)。

| 用户要找的内容 | 回顾入口与含义 |
| --- | --- |
| 一段专注经历 | 查看本段计时、小步骤及相应结果；小步骤不证明任务完成，未填时不猜任务名 |
| 所属或独立想法 | 可从原段或想法视图找到同一条目；独立想法无需先有专注，空记号不强制补字 |
| 伙伴生活与当时的故事 | “生活场景”展示逐渐丰富的综合小屋；从物件来由或“回看故事”打开原会话快照。小屋呈现现在，历史保留当时，不建立待处理故事清单 |
| 喜欢或已有的内容 | 在收藏内容区按[内容性质](#collection-kinds)阅读；会话纪念无需再次收藏才保留 |

用户的小步骤与伙伴的小事须可区分。计时8分钟且伙伴读了书，不得合写为用户“读书8分钟”或现实任务已完成。同一题材的不同尝试仍是独立会话和故事实例，不合并时间或跨段接续。

<a id="review-access"></a>

#### A.5.3 可查看的范围

默认回顾已结束专注和独立想法；所属想法随原段查看，也可集中找到。活动会话单列，草稿有恢复入口但不算正式想法。阅读、展开和重读不开始会话、不改待看状态、不推进故事或重新领取所得。

近期计时汇总不是历史保留期限。更早历史仍可加载，旧想法和收藏不受计时窗口隐藏；已收起想法仍可找回。「全部记录」是入口名，不据此新增独立休息历史、操作日志或草稿正式记录。默认模式、按页浏览、按月查找与想法搜索见[A.5.7](#records-ui)；这些是完整记录页的已定要求，交付批次见[5.1](01-product.md#record-delivery)。生活场景、想法和收藏不受近期计时窗口过滤。

#### A.5.4 指标与事实的使用

正式汇总统一读取[指标口径](04-data.md#record-metrics)，不在记录页另写公式、日期或保存条件。显示时说明统计对象和范围；待保存结果、活动会话及读取缺口与已存合计分辨。计时不等于核验过的工作、效率或注意力，不生成表现总分、分心评分或完成率目标。首屏使用[A.5.7](#records-modes)规定的紧凑汇总；更多指标仍依[5.2](01-product.md#record-decisions)评审，不因可计算就全部展示。

<a id="review-actions"></a>

#### A.5.5 操作目的与权限

| 用户意图 | 执行规则与影响边界 |
| --- | --- |
| 查看、展开、切范围或模式 | 只改变查看上下文，依[A.5.7](#records-ui)；不改业务事实 |
| 编辑、收起、删除或撤销想法 | 依[A.2](#f2)修改同一对象；不改原计时或故事，收起不表示现实任务完成 |
| 取消收藏、隐藏纪念、选用已有外观 | 依[A.4](#collection-kinds)区分关系、内容、资格与偏好，不统一套删除动作 |
| 重试读取或保存 | 依[读取与保存](04-data.md#saves)分别处理当前范围或原操作；不因重试新建记录 |
| 导出、替换或清空 | 依[数据管理](04-data.md#backup)；单条专注删除、改时长及补计时仍未进入本期 |

逐项目的、前提、结果、失败与去向见[动作规格](13-actions.md#record-action-contracts)；数据变更与联动以[提交边界](04-data.md#data-mutations)为准，动作表不另立保存规则。

<a id="review-states"></a>

#### A.5.6 跨页面协作

进入记录不隐含暂停。读取、保存与访问限制按[数据状态](04-data.md#data-quality)分别说明；有想法但计时为零，不显示整库为空。阅读或编辑时到期、写入回执或其他窗口变化只作用于对应对象；保护未交输入与阅读位置，不自动跳回专注、重绑便签或补播故事。对象被删除或替换后，不能为维持画面复活旧内容。

页面范围、刷新时机和返回位置统一见[A.5.7](#records-ui)，不在本节维护第二套策略。

##### A.5.7.1 模块与查看方式

页面顺序固定为“记录标题 → 内容选择器 → 当前模式的工具／状态 → 内容”。不再设置占据首屏的大幅氛围头图；角色小插画可以融入内容卡，但不能替代生活场景入口。四个入口始终可见，普通窄屏采用两行；大字必要时改为逐项排列，不截字，不以横向隐藏或更多菜单藏起生活场景。底部仍只有既有专注／记录导航。

| 模式（正式名称） | 工具与内容 | 默认／范围 |
| --- | --- | --- |
| 全部记录 | 紧凑计时汇总、活动／待存说明、月份入口、按日记录 | 冷启动默认；近7天汇总，列表默认全部日期，第1页最多20条最新记录 |
| 只看想法 | 搜索框、月份入口、适用草稿入口、正式想法与空标记 | 不显示计时汇总；含已收起条目，默认全部日期、无搜索词 |
| 生活场景 | 综合小屋、白天／夜晚、查看物件、回看故事 | 不显示计时汇总或7／30天控件；初始布景与已发生变化共同呈现，全部历史可回顾 |
| 我的收藏 | 主动收藏句子，以及可读欢迎笺／已获长期内容 | 不显示计时汇总；按内容性质分组，不承接每段故事纪念 |

**汇总默认紧凑。** 全部记录中用“近7天／近30天的范围＋累计计时＋已结束段数”表达必要事实；“查看统计”展开窗口选择与趋势入口，“收起统计”恢复紧凑层级，默认不展开趋势。只保留一个统计模块，不再叠加今日、本周等大卡。完整日期与待保存／读取缺口说明按事实就近呈现；大字时可换行。切至其他模式即撤下该模块，返回仍保留本次窗口与展开选择。

四模式各自保留本次查看上下文；冷启动重置展示选择，不新增永久页面偏好。日期归档、正式统计和想法归属不由模式选择改写。常规手机视口、默认字号下，全部记录的首屏须能看见首个日期和至少一条摘要；大字与读屏以内容及操作完整可达为先，不能缩字凑首屏。

<a id="calendar-scene-separation"></a>

**日期工具与大场景：功能分开，视觉统一。** 全部记录／只看想法的月份工具放在各自内容区前，打开独立选择面板；生活场景展示同一间小屋当前可信状态，不在大背景上叠加完整月历或用墙面日历作为唯一查找入口。两者使用一致配色、字体、纸张感和边框语言。小屋内若有日历物件，点击沿物件小话规则，只作为生活物件，不暗藏历史筛选。

本版“日历”功能只包含已定的年份／月份选择，不额外增加整月每日格、打卡热力图或任意日期区间。选择过去月份只筛历史列表，不还原“那个月的小屋”，不改变当前物件或昼夜；历史场景按日还原仍未定义，不能由融合背景的视觉暗示为已支持。

<a id="records-browsing"></a>

##### A.5.7.2 时间回顾、明确分页与月份查找

**排序与分组。** 已结束专注按固定归档日分组，同日结束时刻倒序，同刻以稳定ID确定顺序；独立想法按自身创建时刻并入。所属想法仍在原段内，不在全部记录重复列一份；“只看想法”按自身创建日期查看。日标题显示日期和该日可信专注合计；合计不从已加载的几行相加冒充整天。未知日期另设“日期不详的记录”入口，按可信创建时刻及稳定ID排序，时刻也未知则按稳定ID；不归今天，也不被月份过滤永久隐藏。

<a id="record-pagination"></a>

**采用明确分页。** 当前列表一次只显示一页，每页最多20条逻辑条目；使用“上一页／下一页”切换，不继续向页面底部追加，不采用无限滚动。日期标题、统计模块和活动提示不占条目额度。底部翻页控件属于列表，不与固定主导航重叠；列表有内容时可操作到达。

| 浏览动作／边界 | 确定行为 |
| --- | --- |
| 首次进入 | 默认第1页，按既定排序读取最新20条；一页可以含多个日期。没有结果显示真实空态，不显示“第1／0页” |
| 同一天超过20条 | 同一日允许跨页，每页仍有清楚日期标题；日合计是该日完整可信计时，不按本页重算成另一份日合计 |
| 翻到上一页／下一页 | 按当前条件读取相邻页；成功后替换本页列表，并将列表视口／读屏焦点带到目标页首条，不把整页页面强拉到大标题。原统计范围不变 |
| 页码与首尾 | 已知总数时显示“第n页／共m页”，m由同条件可信条目总数除以20向上取整；只有一页时显示第1页，两侧不可操作。第一页的上一页、末页的下一页明确禁用；不靠反复点空页才发现结尾 |
| 总数未齐／加载失败 | 未知总页数显示当前页及加载状态，不填0或猜总页数；是否可翻下一页依可信has_next判断。换页在途不将目标页号配旧内容，失败保留原页与原页码，提供“重新加载” |
| 按月查找／提交搜索 | 在当前模式切换到新条件的第1页；日期／关键词与结果一起更新，明确只查该范围。关闭月份选择器但未选月份不改变原页 |
| 清除月份／关键词 | 视为改变条件，返回清除后的第1页；清除月份保留关键词，清除搜索保留月份。与“关闭详情返回原页”区分 |
| 查看详情／切模式返回 | 当前访问保留该模式的条件、页码、条目ID与相对位置；关闭详情或切回模式恢复原页原位置，不重新从第1页读起 |

总数用于页码，不从当前已加载的一页推算；无需把全量明细一次载入或渲染。翻页请求绑定模式、条件、页码和数据版本，快速点击只让最后仍有效的意图生效，不能在未确认换页时按重复点击连续越过多页。

新记录、删除或搜索成员变化按[查询一致性](04-data.md#data-query)核对：不强迫把正在读的内容跳回第1页，不以旧页号代替对象身份。重读后优先保持当前有效条目的位置并校正页码／总页数；原条目已移除则就近返回，最后一页删空时落到仍存在的最后一页。旧数据版本的页码、总数和新版本行不能混用；读取未齐时保留旧页并标更新，不凭空报已完整。

“选择月份”打开独立年份／月份面板，可直接选年，不需要从本月逐月翻。点选月份即生效并关闭面板，显示“YYYY年M月”，从该月第1页开始，翻页不跨出该月；“查看全部日期”清月份后回第1页。大量记录通过月份或文字缩小范围，再用分页浏览，不要求逐页翻完历史。

月筛选用于历史列表，统计仍按所选近7／30天计算，两者各自在所属模块标明范围，不使用一个日期控件兼管两者。无记录月份可正常选择并显示该月空态；它不表示整库无记录。未知日期入口不混入已知月份合计。

<a id="records-item"></a>

**单条摘要定稿。** 专注显示可信起止时间、实际计时和可选小步骤；有故事时补故事名称／当次短摘要，有关联想法时给明确文字入口，不能只留无名称的小图标。未填步骤不猜任务标题，故事行为不冒充用户任务。独立文字想法显示创建时间及正文前两行，空标记显示“留过标记”和“补充文字”。长内容截断须有展开入口，不靠大图占满记录流。

<a id="review-window"></a>

**计时窗口。** 近7／30天为设备当前日期向前6／29个日历日，包含今天；它不是保留期限或下方列表条件。进入记录、切窗口、回前台、日期／时区变化时核对；已提交事实变化时重读受影响结果。范围、汇总、趋势一致更新，未齐时旧范围配旧值并标更新，不能新日期配旧数字。改变窗口不重置列表月份、展开或位置；月份与加载也不改变窗口。查询迟到、分页去重和数据世代依[C.5](04-data.md#data-query)。

20条是本版默认交互参数，不是用户可保存的上限，也不是已验证的最优性能参数；实现可选择等价缓存／虚拟化，不能改变分页、焦点和完整性承诺。

<a id="records-thought-search"></a>

##### A.5.7.3 想法浏览与文字搜索

“只看想法”直接展示正式文字与空标记，包含已收起、排除已删除；草稿独立提供“继续草稿”。按创建时刻倒序，每页20条，并可使用自己的月份条件；不继承全部记录的月份或计时窗口。

搜索框提示“搜索想法”，用户点“搜索”或键盘搜索键后执行；不在中文输入法组合过程中提交。搜索当前全部有效正式正文，与已选月份取交集；没有选月时搜索全部历史，不只搜索已经加载的条目；日期不详但正文可信的命中也纳入，在已知日期结果之后单列日期不详分组，分页仍统一每页20条。采用连续文字包含匹配，去除查询首尾空白、比较时规范化Unicode并忽略英文字母大小写，标点按字面处理；不做分词、模糊猜测、情绪分析或故事文本混搜。匹配规则详见[C.9.6.1](05-data-fields.md#record-read-contract)。

当前生效搜索词及“全部日期／YYYY年M月”一起显示；输入中的新文字不能冒充已经生效的条件。空查询等于普通浏览；“清除搜索”只清关键词，保留月份；返回清除关键词后该月份／全部日期的第1页。非空搜索不匹配空标记或未提交草稿；结果按原创建顺序，每页20条，不按编辑时间置顶。

打开、编辑后回相同查询及条目。保存后不再匹配时，先保持当前阅读／编辑结果和成功反馈；退出详情时回结果中的就近条目，并说明原条目已不符合当前条件，不为保留位置伪造命中。读取失败保留输入、已读内容及重试；切换查询、月份、模式或数据替换后，旧响应不能覆盖新意图。

<a id="records-navigation"></a>

##### A.5.7.4 阅读、编辑与按来源返回

每个模式保存当前访问的有效条件、页码、对象／日期锚点及相对位置；生活场景还保存昼夜显示选择、物件／故事ID与详情来源。关闭、切模式、暂去专注再回来恢复对应上下文，不统一跳到顶部。主动改变月份／提交或清除搜索回第1页，明确翻页到目标页首条；重试、反馈、到期或后台新增不强迫滚回第1页。一次最多展开一条记录；长内容在可关闭阅读区查看。正文按同ID最新合法版本读取，故事按当时快照读取。

从生活场景进入对应专注是带来源的阅读，不悄悄改变全部记录原来的月份和滚动位置；返回先回原物件／故事详情，再可返回小屋。读记录不等于编辑，关闭／折叠不执行想法收起、删除、取消收藏或重新领取。对象失效说明原因，回同条件的就近条目；原日期或物件已无合法内容则回其上级列表或可信小屋状态，不显示幽灵对象。

**编辑按来源返回。** 保存成功回原条目阅读，修改日不作创建日置顶，不自动跳专注。能安全保留草稿时直接离开，不每次切模式都弹保存确认；冲突、明确放弃／替换或无法可靠保留时才请求必要决定，保护未交输入。用户主动续写才唤键盘。删除／取消收藏成功后焦点交还下一条、再上一条、再所属区域；不自动展开邻项或开键盘。撤销恢复原位置但不强制追随滚动。搜索成员变化另按A.5.7.3。

活动会话和待存结果须可辨，进入记录不改变计时状态；返回专注仍是同一真实会话／准备态。运行提示在各模式采用简短状态行；本次阅读中保留其占位，结束／保存反馈替换内容而不推移正在读的条目。没有相关状态时不显示虚假提示，不把活动时间计入正式汇总，不抢阅读焦点。

##### A.5.7.5 空态、读尽与异常

| 状态 | 呈现与可用路径 |
| --- | --- |
| 月份没有记录 | “这个月还没有记录。”；保留“选择月份／查看全部日期”，计时汇总按自身范围表达，未知日期入口仍可达 |
| 搜索无命中 | “没有找到匹配的想法。”；保留关键词、月份与清除入口，不能显示整库为空 |
| 尚无故事积累 | 仍显示初始小屋；物件列表区分初始布景，“这里还没有新的故事痕迹。”仅用于积累部分。待存／旧内容分别说明，不用空白房间或催收集取代 |
| 首尾页／无结果 | 可信页码与前后页可用性表达边界；无结果显示对应空态。只显示当前一页时不写“已显示全部记录／物件”；未知总数不冒充末页 |
| 尚未加载／读取失败／部分可读 | 就当前区域说明加载范围与“重新加载”，保留已读对象；局部数据不冒充完整汇总或完整物件／故事集合 |
| 草稿或结果未存／保存失败 | 保留原文、真实结果及原操作重试；未确认前不宣称永久物件已留下，一条成功不替另一条报成功 |
| 只有图形不可用 | 时间与可信摘要可读，图片占位尺寸稳定；不猜历史、不换成今日房间 |

其他空态沿[A.5](#review-states)和[B.6](03-ui.md#ui-copy-catalog)；加载、搜索或保存反馈都不能弹出无关角色鼓励。

<a id="record-linkage"></a>

##### A.5.7.6 控件联动与长期验收

| 变化来源 | 应更新什么 | 应保留什么 |
| --- | --- | --- |
| 切近7／30天、日期边界更新 | 范围、正式汇总与趋势的一致结果 | 所有列表条件、展开、锚点；不重排想法或改变小屋物件 |
| 切查看方式 | 当前模式工具／内容及对应状态 | 各模式自己的条件与位置、计时状态、草稿 |
| 月份／搜索／清除条件 | 当前模式的有效范围与第1页结果 | 计时窗口、其他模式上下文与原始数据 |
| 上一页／下一页 | 同条件目标页、配套页码与首尾状态；失败提示只作用当前请求 | 统计窗口、其他模式位置不变；成功替换列表，失败留原页，不追加 |
| 日历／背景呈现 | 月份只筛对应历史列表，昼夜只换小屋呈现 | 当前小屋事实不随历史月份变化，不暗示支持按日还原房间 |
| 想法或收藏写入确认 | 同一对象的正文／状态及查询成员资格 | 原计时、故事、创建时间；按来源返回 |
| 故事节点／会话结束确认保存 | 节点更新本段检查点；手动结束更新真实小记；符合收集条件的到期才更新小屋与来由，终态保存后更新计时汇总 | 保留阅读与输入；不抢焦点，未存不报已留下；物件详情保持位置 |
| 切白天／夜晚 | 当前小屋背景与光线层、选中项 | 物件身份／状态／位置、历史快照、计时和保存状态不变 |
| 替换数据／删除对象／只读 | 世代、对象有效性、对应查询及操作权限 | 可保留输入；旧游标与旧回执不能复活上一世代内容 |

只读仍可搜索、筛月、加载和阅读可信内容；不把整页锁住。完整记录页须用1,000／10,000段数据验证三个任务：记得日期时按月找回、记得文字时搜索想法、记得伙伴经历时从小屋物件来由或回看故事找回；并记录正确对象、步骤、耗时、放弃点及返回位置。测试定义见[D.19.2](07-acceptance.md#record-scale-tests)。分页性能通过不等于找回易用性通过；失败时修正路径并重测，不能退回“无限翻页最终能到达”的验收。

### A.6 设置

设置分为常用偏好、数据管理、应用说明。时长可用整数输入与加减；提交／离开字段时校验，非法值可恢复上次值或明确放弃。声音、减少动态、场景展示、节点鼓励、纪念展示各自说明生效对象。新安装默认声音关闭，用户原有选择保留；到时声仅在获准且近期发生时播放，主动试听不模拟到期。数据预览与清空确认在原区域进行，系统文件选择器按平台能力使用。异常不遮住计时主操作；说明仅本机保存的范围和可行的下一步。

**未改动、改动与重置分开。** 字段只有合法且与已生效值不同才发普通补丁；原样失焦不清记忆。明确恢复默认时长独立提交三类默认与单次时长记忆，不改声音、场景、故事或记录。快速操作使用确定目标值，不由迟到回执反转控件；系统播放限制与减少动态状态不回写为用户主动偏好。回执只使它捕获的旧准备依据失效，不清后来明确重选值。

**设置的影响范围。** 声音只影响到时提示，允许主动试听，声音不可用时计时照常。系统或应用任一要求减少动态时使用静态。更新偏好按字段生效；旧回执不覆盖更新的决定。缺席或新增内容不重开用户关闭的展示，也不生成待补看的剧情队列。重置时长仅重置三类默认时长和单次时长记忆，不清记录或其他偏好。数值合法再提交，非法或输入法组合态保留编辑值，允许恢复上次有效值。
