## 不要混淆的几件事

- **事实记录与收集不同。** 手动结束保留短章小记，自然到期保留完整章页。只有自然到期、故事完整且保存成功，才按[收集规则](02-features.md#rule-collect)进入生活积累。
- **暂停与已结束不同。** 原会话暂停可以继续；结束后不保留未完事项，新会话不继承旧段进度。
- **已确认性格与内容候选不同。** 好奇、有自己的小主意、认真但不较劲，加轻微笨拙已经确认；具体台词、偏好和桥段仍按各自状态使用。
- **台词不附带动画义务。** 在已有简单画面里自然成立；不能为让一句话有趣，默认增加细微表情、手指动作或连续分镜。
- **规则、实现、验证分别记录。** 有需求或字段不等于已有功能；报告通过也只证明对应提交与测试范围。

## 修改时保持这张地图有用

一条详细规则只在一个模块维护，其他位置引用。改产品意义时同步相关功能、数据与验收；只改台词时保留稳定内容身份和旧收藏快照，不顺带更改触发或收集规则。新增文件时在本页说明它负责什么、谁需要读，并更新相邻入口。

原来的A／B／C／D／E／F编号作为查找编号继续保留，跨文件引用使用可点击链接。移动或重命名时修复引用；不要重新使用已退役编号。文案候选与已确认规则都明确标状态，发现矛盾先写清场景与两条冲突规则，不以实现方便代替产品决定。

提交前运行 `python3 scripts/check-prd-docs.py`，检查本目录及主要工程入口的链接、锚点和文档地图。应用代码有改动时，再按AGENTS要求补相应测试；文档发布和网站部署结果分别记录。
