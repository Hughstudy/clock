## 研究问题与证据边界

目标是让伙伴有自己的愿望和有辨识度的选择，同时适合短暂、低注意力、可以随时暂停或离开的专注场景。先前用户确认的三项主性格及轻微笨拙保持不变；“台词不能给画面增加很多压力”是本轮筛选条件。

本轮查阅创作者课程、角色官方介绍、游戏设计者文章与演讲公开简介，并做多轮针对本产品的反向检查。以下区分**来源直接说了什么**与**我们怎样使用它**。没有观看未能访问的课程视频或付费演讲，也没有做用户访谈、原型试用或吸引力测量；不能据此声称已经证明人物会受到普遍喜爱。

## 第一轮：从性格词回到愿望、选择与后果

Pixar in a Box 的角色术语将想要、需要、障碍、选择造成的改变和后果分别说明。[R1] 对本项目有用的不是照搬电影规模，而是把“好奇”落实到它会主动做哪件事，把“有小主意”落实到它会选哪种办法。

**修正：** 不再追加“温柔、治愈、乐观”等词作为人物深化的主要成果。每张样稿都要能指出一个具体意愿和一个属于它的选择。这里是评稿方法，不是新增产品流程。

**反问：** 一定要给它创伤、重大缺陷和彻底转变，才能有弧光吗？课程框架能帮助构造电影，但不能证明专注伙伴也需要同样规模的成长。于是把候选弧光缩小到一次改主意、一次确认偏好、一次允许意外，而不写“用户把它治好了”。

## 第二轮：长期角色能否既熟悉又有变化

Peanuts 的官方 Snoopy 介绍把读写、想象与普通生活的享受放在同一个角色里，也收录了 Schulz 关于角色能经历不同成败的说明。[R2] Aardman 对 Shaun the Sheep 的官方介绍展示了熟悉场景下持续变化的短篇题材。[R3]

**推论：** 可重复相处的角色不必每次换性格，也不必每次修复同一个缺点。稳定的偏好可以在不同事情里产生不同选择。作品案例能说明这种创作可能性，不能证明某项特征单独导致受欢迎。

**修正：** 把“角色真的随前情改变”与“读者逐渐看见它的不同面”分开。当前产品优先做好独立故事里的辨识度；长期变化只有在事实可追溯时才成立。

**没有照搬：** Snoopy 的身份幻想、Shaun 的密集闹剧与多角色配合，不作为新世界观和动画要求。学习的是人物选择与短篇关系，不复制形象或剧情。

## 第三轮：舒适不等于没有意愿，戏剧性也不等于压力

Project Horseshoe 的设计者报告把安全、充足与柔和作为讨论舒适体验的维度，并强调自主选择及避免强迫。[R4] 这是实践者提出的设计框架，不是针对本产品的实验结果。

作为反例，Wanderstop 的 GDC 公开简介明确谈到通过机制制造不适，反思玩家对舒适游戏的期待。[R7] 这说明温暖的视觉可以承载尖锐主题；但这个番茄钟的产品承诺并不是要求用户经历这种张力。

**修正：** 让小矛盾发生在角色自己的日常选择里。它可以觉得自己摆的东西挤，可以有一瞬间不甘心；但用户停止计时不能触发它受伤、失望或需要安抚。允许人物有情绪，不允许把用户操作变成情绪债务。

**否决的方向：** “怕做不好、在用户陪伴下逐渐学会放下”有明显成长线，却更容易制造照顾义务，并重复产品已经表达的道理。保留它的独立生活，把内在张力改成对自己的小主意有一点偏心。

## 第四轮：电影剧本的写法，能否直接放进简单画面

inkle 的《Pacing dialogue》区分了依靠演员完成表达的影视台词，与需要在有限画面中自行传达意思的游戏文字。[R5] 该文自己的多段气泡节奏适合其叙事游戏，不能直接移植为专注中的连续对白。

**修正：** 先拿掉细微表情、动作节拍和声效，再读台词。用具体意愿或取舍承担性格；如果笑点需要精准手指动作或专门特写才能成立，先改词或删掉笑点。

**进一步反问：** 这样是否会把台词全部写得很平？不是每句都需要独立成为笑话。泛泛评价可以删除；“这本先不收。我还想看。”虽然朴素，却有对象、选择和人物偏好。趣味应来自故事里的位置，而不只来自句子表面。

## 第五轮：可跳过、可打断，弧光还能成立吗

Emily Short 讨论 storylet 时，以内容、出现前提和对世界的影响为基本构成，并提到用纸卡试做。[R6] 对这里的启发是先把小故事写成可核对前提与结果的单元；不是引入新叙事引擎或把收集变成游戏关卡。

**修正：** 默认每张人物卡独立可读。有明确前后呼应时，只引用真实完成并保存的事实；无依据时用独立说法。结尾收集继续遵循现有规则，不用“人物成长需要”覆盖计时、保存或结束行为。

**发现的冲突：** 如果一边允许乱序观看，一边声称角色已从第一阶段成长到第三阶段，就在叙事上夸大了变化。解决办法是把本期目标写成“不同选择让人物越来越清楚”，把确有前后因果的成长留给少量有合法前情的内容。

为检验“真实成长”是否只是空话，讨论稿另留一个旧物选题：从为旧物找到用途而得意，走到可以承认别的物件更合用，同时仍保留自己的喜欢。它有可辨认的前后选择，但需要合法前情与额外内容成本，因此只作为后续方向，不包装成当前已有能力。

## 第六轮：拿样稿反过来推翻设定

纸面检查使用了清桌、重读、车票、多肉、书堆、再次读书六张卡，详见[讨论稿](15-character-arc-proposal.md)。检查发生在文稿层面，没有把设想当作已运行的测试。

| 反向检查 | 发现的问题或风险 | 本轮调整 |
| --- | --- | --- |
| 每张都安排“出错后接受” | 笨拙抢走人格主轴，反复讲同一个道理 | 只留一张刻意失误卡；其余分别试成功、取舍、享受与保持原样 |
| 每张都让它想新办法 | 好奇变成坐不住，小主意变成表演任务 | 增加不重摆、不追新的日常；熟悉也可以是它主动喜欢的结果 |
| 把“改主意”当成唯一成熟反应 | 人物又变成总是正确、永远开明 | 它也可以坚持一个安全、合用但不最整齐的偏好 |
| 仅用聪明台词证明可爱 | 容易出现 AI 感、金句堆叠，与生活脱离 | 把台词放回具体事实；无话可说时静默 |
| 为一句“坐会儿”默认补坐下动作 | 看似轻台词仍可能偷带制作要求 | 绑定宿主姿态，不匹配就改词；不声称所有样稿零成本 |
| 把已看台词当作成长证据 | 错过呈现或提前结束可能制造假前情 | 只使用真实、已保存且符合收集规则的结果 |
| 只留下柔和、体贴 | 安全，但具体选择仍然可替换 | 保留轻微小得意与对自己点子的偏心；关系上的善意稳定 |

## 这一轮能够下的结论

推荐以“对自己的小主意有一点偏心”连接已有主性格，以独立小事中的具体选择写出人物，以真实生活结果形成熟悉感。这个方向通过了本轮对产品规则与纸面样稿的自检，值得进入讨论；尚未证明台词的实际吸引力、长期不腻或画面制作成本。

暂不把研究扩展成完整身世、关系系统或连续剧情。接下来最有价值的证据是用户对同场景两种写法的判断，以及简单静态样稿在真实专注使用中的表现。
