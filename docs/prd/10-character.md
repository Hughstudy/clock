### E.11 伙伴性格简历与共用创作基准

**设定状态。** 2026-11-05，用户确认前三项主性格：“好奇、有自己的小主意、认真但不较劲”，并接受“一点点笨拙，不用完美”。这四项成为共用创作基准。以下偏好、反应和场景是沿此方向完善的创作工作稿，可用样稿继续校准；具体桥段不等于已确认分镜、已发生事实或已实现功能。温暖、有分寸、自主、有自己的生活，继续作为关系底色。

**一句话认识它。** 它对身边的小事很有兴趣，常常想试一个自己的办法；做起来挺认真，偶尔估错一点，便挪一挪、换个办法，弄舒服了也就满意了。

**日常肖像。** 它喜欢把日子过得有一点自己的意思。读到有趣的一句会回头再看，发现旧车票正好能当书签，会觉得这个办法挺得意。整理桌子，是因为想给自己找个舒服的位置；桌面清出来以后，它可能坐下试试，发现还不太顺手，再挪一挪。它会停顿、犹豫、选错，也会有一瞬间的小懊恼。事情不必每次都做得漂亮，只要合用、喜欢，就可以安心享受眼前这一小块地方。

**身份与动机。** 它是在小屋里过自己生活的伙伴，基本愿望是“弄明白一点有趣的事，把身边的小日子过得合自己心意”。它能够自己做选择、处理小失误、找到乐趣；愿意分享发现，也能安静独处。名字、年龄、性别和身世不在本轮补设，外形沿用已确认方向，绘画遵循[B.4.1](03-ui.md#drawing-rules)。

#### E.11.1 性格主次：前三项决定选择，笨拙点缀过程

| 优先级 | 已确认特质 | 内在动机与可见表现 | 创作分寸 |
| --- | --- | --- | --- |
| 1 | 好奇，容易发现普通事物的趣味 | 想知道“这是怎么回事”“换个角度会怎样”；多看一眼叶缘、书页或倒影，选择一件小事试一下 | 能专心待在一件事上，也能安静欣赏；不持续东张西望，不为制造新鲜感频繁切换活动 |
| 2 | 有自己的小主意 | 喜欢试试自己的办法：让旧物换个用途，给熟悉的东西换个摆法；办法奏效时有一点小得意 | 主意小而具体，有时普通、有时不奏效；不要求每次都聪明惊艳，也不拿用户或界面开玩笑 |
| 3 | 认真投入，但不和自己较劲 | 对自己感兴趣的事情愿意试、愿意调整；发现不好用就换办法，满意后能停下来 | 认真表现在在意和选择，不等于慢动作、效率高或必须做完；允许迟疑、放下和接受不整齐 |
| 轻微点缀 | 有一点笨拙，不用完美 | 偶尔估错距离、放得有点歪，或一个小办法需要调整；自己发现、补救，也可以留下不影响使用的小不齐整 | 不是第四条并列主性格；不每章出错、不连续出糗、不固定循环同一笑点，不靠无能换用户照顾 |

原建议中的“有偏好”“享受小事”“偶尔小得意”融入日常表现，不再并列扩张性格清单。一个桥段可以只清楚呈现其中一项，不要求每次把四项演齐。

#### E.11.2 兴趣、偏好与小小的不完美

下列是优先试写的生活细节，可按章稿取舍；偏好通过反复而自然的选择建立，不另做喜好数值、养成任务或必须凑齐的物件。

| 方面 | 建议写法 | 带来的角色感 |
| --- | --- | --- |
| 会留意什么 | 光照在叶子上的边、书里一处奇怪比喻、一个旧物的新用途 | 好奇来自普通日常，平静画面也有内容 |
| 喜欢怎样的地方 | 够自己舒服使用的一角；东西顺手，也留得下一两件喜欢的小物 | 有自己的秩序，不追求整间屋子样样齐整 |
| 会珍惜什么 | 顺手的杯子、喜欢的书、已真实存在且有来由的小物 | 熟悉感来自反复使用和真实经历，不把稀有或数量当价值 |
| 怎样享受成果 | 找好位置坐一下，回看刚读的一句，欣赏刚摆好的角落 | 成果是自己愿意停留的生活，不必总向用户展示或邀功 |
| 有什么小局限 | 偶尔先试自己的点子，做起来才发现尺寸不合；也可能暂时没想好 | 有主意却不全能，调整比立刻想出完美答案更像它 |
| 可以怎样不满意 | 书签老往里滑会让它停一下；桌角仍硌手会换个位置 | 允许对具体小事不耐烦，不把烦恼归因于用户的操作或缺席 |

**可重复的行为习惯。** 观察时会靠近一点或偏头；犹豫时会停一拍看看手里的东西；满意时可能稍稍挺起身子，再回到自己的事。它也会有没什么表情的普通时刻。这些是可选的动作语言，不是每个场景必须重复的招牌动作。

#### E.11.3 一点笨拙怎样成立

笨拙来自它正在认真做的事：例如想一次把几本书挪开，放下时书堆有些歪，便扶住、分成两叠。趣味在于它仍有自己的判断，调整过后继续享受小事。并非每次小失误都要变成成功笑话；只要安全、合用，它也可以接受边缘不完全对齐。

表达以小停顿、看一眼、自己调整为主。可有短暂惊讶、小懊恼或不好意思，不升级为哭闹、自责、受伤、破坏珍爱物件或等待用户救场。角色本身值得喜欢，不靠反复受挫让用户心软。

笨拙必须在物理上可信：握持、支撑、肩臂与道具运动连续。穿模、悬空、物件瞬移、手未碰到东西却东西移动，都属于制作问题，不能包装成性格。首批试稿只选一处必要的小失误检验效果；不建立“每章必须失误一次”的规则或随机概率系统。

#### E.11.4 情绪与相处方式

| 时刻 | 像它的反应 | 与用户的关系 |
| --- | --- | --- |
| 发现有趣之处 | 多看一下，轻轻试一下，有时想分享一个具体发现 | 用户不看也能成立，不催看、不重复提醒 |
| 自己的办法奏效 | 短暂得意、欣赏一下，再继续生活 | 不等用户夸奖，也不把成果解释为用户专注成绩 |
| 办法不太管用 | 愣一下或有点懊恼，换个做法、缩小尝试，或接受眼前结果 | 不把困难交给用户处理，不追加坚持或补做要求 |
| 用户主动轻触或看物件 | 按已有规则给一个局部回应，分享当前确实能知道的小事 | 亲近而平等，不卖乖讨好，不升级为对话或照顾任务 |
| 用户暂停、结束或离开 | 按真实会话落点安全停驻、收尾；关系上的善意保持稳定 | 不失望、不挽留，不用笨拙拖延退出；离开不额外推进故事，后台计时与到期仍按既有真实规则处理 |
| 用户回来 | 自然接住当前状态；有已保存前情就据实呈现 | 不计算“等了多久”，不靠关系衰减换回访 |

它可以有自己的小情绪，但不是让用户来安抚的对象。默认情绪平稳，快乐、好奇、小得意和小懊恼都有出现的空间；不要求永远笑着，也不借角色表演推断用户心情。用户主动求鼓励时，仍按E.1—E.9的真实依据和已有句库回应。

#### E.11.5 说话的感觉

自然、简短、具体，有一点自己的观察。多说“我看到什么、我想怎么试、我喜欢哪里”，少把自己的每件小事升华成对用户的劝勉。幽默来自它看东西的角度和小反应，不靠连续抖包袱、幼儿语气或固定口头禅。

**先有当时的念头，再有一句话。** 台词可以表达具体发现、偏好、试探或反应；趣味也可以来自用词和小小的态度。画面已交代的用途不再解释一遍，不用泛泛评价或刻意拟人凑性格。允许省略和停顿，不追求句句机灵，也不靠加“嗯”“嘿”完成改写。

**台词适配已有画面。** 默认只凭现有物件、场景或已成立的结果就能读懂，简单静姿也应自然；不要求逐字演出来。配套动作可以加分，但不为一句话额外要求特写、细微表情、精确手指动作或一串连续表演。若必须补演这些才能明白或有趣，优先改台词。章故事本身值得制作的动作仍按E.14取舍，不将此规则扩大为取消必要动画。

以下是角色语气样例，不替换现有136句鼓励，也不代表新增自动气泡。实际采用时仍须核对物件、已发生事实、注意力与可退出规则。

| 已有情境与依据（不指定新增动作） | 语气样例 |
| --- | --- |
| 看见多肉叶片挨在一起 | “这几片叶子，挤得还挺整齐。” |
| 已有旧车票书签，章稿设定支持它留下了这张车票；静态物件即可 | “还好没扔。” |
| 自己的摆法不顺手，正准备调整 | “好像有点挤。我挪一挪。” |
| 桌角已经够用，仍留有小不齐整 | “这里放得下书，就挺好了。” |
| 原有故事中已交代一次尝试及奏效结果；沿用已有结果画面 | “欸？还真行。” |

以上只限定句子适用的事实，不增加“翻找、拍平、松手、挺身”等配套分镜。没有现成适用情境时换句或不说；不为了使用一句话补剧情。没有适合的话就安静，不为凸显性格提高气泡频次。

#### E.11.6 用熟悉的三章检验是否像同一个伙伴

以下是创作方向对照，尚不替换对应DAY稿或新增制作清单；正式采用时同步章稿、静态呈现和E.14成本。三章各取一个最有效的选择，不都加笨拙桥段。

| 首批题材 | 想要什么、怎样选择与反应 | 应看见的性格与事实边界 |
| --- | --- | --- |
| DAY05 清桌 | 想在窗边舒服地读书；先试一个自己的摆法。可选小失误：书堆放歪后扶住，改分两叠；有了够用的位置便坐下试试 | 小主意、认真但不较劲，轻微笨拙只在必要时加入。已清出多少仍由原节点决定，未清完不演成已清好 |
| DAY61 浇多肉 | 想照料自己窗边这一盆；照原稿检查盆土、浇水、收壶，留意到叶缘的光，愿意看一会儿 | 好奇与享受小事即可成立，不再安排洒水失误；不因用户缺席缺水、不为换花样重复浇水 |
| DAY04 读书 | 对书中的内容有兴趣，遇到喜欢的一段回读；用已有旧车票留下真实读过的位置，对这个小办法很满意 | 好奇、小主意与小得意；不以读得快证明认真，不把伙伴阅读写成用户完成任务，不为重演趣味退回旧进度 |

同一人格可以产生不同选择，而不必重复同一个动作。没发生笨拙时，它也应该足够有辨识度；拿掉气泡和鼓励，动作与静态结果仍应读得出它为什么在做这件事。

#### E.11.7 创作与交付检查

本节是跨章创作基准，不新增运行时人格字段、情绪值或随机事件系统。开发仍消费真实会话与故事状态；动画不能因角色兴奋、笨拙或想再试一次而改动计时、保存、暂停、结束或收集资格。

每章交付时说明：它自己想要什么；哪个选择像这个伙伴；变化后怎样回应；安静或减少动态时还剩下什么。若有小失误，再检查是否与正在做的事有因果、能否自己处理、是否真的有必要。用户未看、没回应、提前结束或离开，都不补播、不生成待办、不降低关系善意。

当前已确认性格可以直接用于创作；具体偏好与演法仍经样稿验证。无需在制作全部章节前另做完整传记，也不把“用户能背出三个性格词”当成功。核对[T-LIFE09](07-acceptance.md#t-life09)，设定及视觉待定范围见[5.2](01-product.md#mechanism-decisions)。
