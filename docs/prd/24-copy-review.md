## 本轮取舍

**后续复盘，2026-11-23：** 用户指出61句不足以支撑长期随机相遇，语义和句式仍过于集中。[25中的研究与重审](25-language-variety.md)纠正把自然、友好过度理解成压短和削减的取舍。本页保留当时决定，不把旧审稿结论当作新稿的机械禁令；线上原文目前仍以09为准。

199项中，38项原文保留、45项修改、116项删除。177句角色台词中，19句原文保留、42句修改、116句删除；最终运行61句，其中自动节点22句、主动支持39句。删除项包含25句此前就不再自动触发的工具节点旧话，其余91句从可选池退出。

先逐句看事实、用途与口语，再按同一场景合读去重，最后把剩余句子放回真实操作：刚点开始时是否还要教怎么开始，疲惫时能否直接回应，没展示动作时台词能否成立。没有为了各类数量相同重新填句。这是编辑判断，不代表用户喜爱度已经验证。

| 检查角度 | 本轮处理 |
| --- | --- |
| 口语是否顺 | 去掉“温柔地记住”“小小的落脚处”“试个头”等书面化或别扭表达；保留普通招呼，不要求句句出金句 |
| 有没有真实作用 | 开始后不再连续指导怎么动手；欢迎笺说明相处与操作；求鼓励时不能只谈自己的兴趣 |
| 是否重复 | 同一个“先做一点”“可以休息”“回头找书签”保留有用版本，不靠换道具凑数量 |
| 是否凭空引入压力 | 删除“我不催／不追问／不闹别扭／不会不高兴”等无须自证的表态；不先引入成绩、承诺、照顾角色的负担再安慰 |
| 趣味是否落地 | 保留折歪的纸船、倒着看书等简短趣味；用一般习惯或往事表达，不声称此刻发生了未呈现的动作 |
| App 能否接住 | 删除“歇着时再聊”等无后续对话承接的承诺；固定保存、错误与计时结果准确，不随机 |

每次打开和合法触发仍直接随机抽取，只避开同池相邻同句。删掉的编号不分配给新内容；旧收藏保留保存时的文本与版本，仍可重读和取消。欢迎笺采用当前版本，本次不改变首次首屏安静的规则。
