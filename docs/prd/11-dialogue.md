### E.10 物件小话：伙伴围绕物件说几句

**正式规则。** 明确设计为互动的物件，以伙伴第一人称表达自己的观察、偏好、趣事或已收集经历；普通装饰不必逐件写小话。每条绑定object_key、适用状态及版本，1—2短句；初始互动对象可说话。首版预写本地文本，不读便签／任务生成内容，不新增聊天、语音、收藏或奖励按钮；不把物件说成用户供养的结果。

以下是首轮内容样例，须与最终画面和章稿状态核对后交付；不是已经上线或已发生事实的证明。

| 物件／适用状态 | 小话样例 | 必须核对的边界 |
| --- | --- | --- |
| 窗边小桌／初始可见 | “我喜欢坐在窗边。书翻累了，就看看外面。” | 表达角色偏好，不声称桌子已清好或由用户获得 |
| 已有多肉／可见 | “叶子挤在一起，像在开一个很小的会。” | 不要求已浇水，不模拟饥渴，不把浇水写成即时开花 |
| 车票书签／章稿已交代伙伴留下旧车票并用作书签 | “还好没扔。” | 须有留下车票并用作书签的真实章稿依据；不补写旅行经历，不伪造用户阅读页数或未发生剧情 |
| 相框／对应放好照片的事实已保存 | “我挑了这张笑歪的照片。每次经过，都觉得它也在笑。” | 相框题材尚未制作时不显示；仅适用章稿中那张已有来由的照片 |

初始互动对象讲自身特点；小屋物件只读初始／已收集状态，不能引用当前段未收集过程或泄露未来成果。无合法匹配时显示名称与中性状态并标记交付缺口，不编完成夸奖。纯装饰不因能画出就新增小话入口。具体交互见[A.3.2](02-features.md#object-talk-flow)。

## 日常台词候选：48句

**状态：创作候选，尚未接入应用。** 这些文字丰富伙伴的偏好、好奇、小主意和一点不完美，不替换既有鼓励库。每组是可选说法，不是一段连续对话，不需要全部播放。一个普通静态场景或已有结果即可承接；不为台词增加新物件、特写、动作、剧情分支或记忆字段。

优先用于用户主动点开已经设计为互动的物件。组名只是编辑分类，不表示新增互动入口；窗边、杯子等若仍为普通装饰，就继续作为候选保留。有现成故事节点时可选相符的一句，但不另开定时搭话机制。每行的适用条件是内容编辑说明，不是新增数据模型；当前状态无法证实时换句或留白。

### 窗边：有偏好，也有一点自己的说法

适用于已有窗边空间及对应阅读入口，不要求画出窗外新景物。

| 编号 | 台词 | 适用说明 |
| --- | --- | --- |
| DLG-WIN01 | 我挑座位的时候，比挑书认真。 | 角色偏好；静态窗边即可 |
| DLG-WIN02 | 还是窗边好，发呆也有个方向。 | 轻微趣味，不要求新增远景 |
| DLG-WIN03 | 这儿我挺喜欢的。没什么特别理由。 | 允许普通喜好，不编物件经历 |
| DLG-WIN04 | 有时候坐好了，就不太想挪窝。 | 一般习惯，不要求演挪动 |
| DLG-WIN05 | 这里放本书，再留一点地方给我，就够了。 | 已有书桌与书；不要求立刻整理 |
| DLG-WIN06 | 我喜欢旁边空一点，脑袋倒可以想得满一点。 | 角色自己的偏好，不评价用户想法 |

### 书：兴趣会把它留下来

适用于已有书本或读书场景。阅读偏好不证明用户读过书，也不推进伙伴的书签。

| 编号 | 台词 | 适用说明 |
| --- | --- | --- |
| DLG-BOOK01 | 遇到喜欢的一句，我会倒回去再看。 | 一般习惯，无需新增翻页动作 |
| DLG-BOOK02 | 我不太舍得一下子看完喜欢的书。又忍不住想往后翻。 | 小小的矛盾，普通书本即可 |
| DLG-BOOK03 | 书厚一点也好，能看好一阵。 | 仅用于画面确为厚书 |
| DLG-BOOK04 | 这一句我想了半天。先夹着吧。 | 已有稿明确这一处停读；不另加动画 |
| DLG-BOOK05 | 有些地方第二遍看，我还是会笑。 | 阅读偏好，不要求此刻笑或新增书中文字 |
| DLG-BOOK06 | 我猜结局的时候，通常挺有把握。猜完再说。 | 轻微自信与自知，不剧透或承诺结果 |

### 旧车票：舍不得扔，正好有用

只用于已设定的车票书签；不虚构目的地、旅行日期、同伴或用户经历。

| 编号 | 台词 | 适用说明 |
| --- | --- | --- |
| DLG-TICKET01 | 还好没扔。 | 与E.10短句同文，是可复用候选，不重复发放 |
| DLG-TICKET02 | 舍不得扔的东西，偶尔还真能用上。 | 已有旧车票书签即可 |
| DLG-TICKET03 | 夹这儿正合适，省得我折书角。 | 书里已有书签，不需演夹入过程 |
| DLG-TICKET04 | 我就是喜欢这张，换新的也不换。 | 表达偏好，不要求用户提供新物件 |
| DLG-TICKET05 | 书签不用太漂亮，找得着就行。 | 不能因此故意降低画面清晰度 |
| DLG-TICKET06 | 别的车票我不好说，这张还得留着。 | 不新增其他车票资产或收藏任务 |

### 杯子：顺手的小东西

只在现成杯子已被指定为互动对象或已有对应节点时采用，不新增饮料种类、液体特效或温度状态。

| 编号 | 台词 | 适用说明 |
| --- | --- | --- |
| DLG-CUP01 | 杯子嘛，拿着顺手就很难换了。 | 一般偏好，无需拿杯动作 |
| DLG-CUP02 | 我有自己喜欢的杯子。喝水也挑这个。 | 不要求画出多个杯子 |
| DLG-CUP03 | 它就放这儿，我伸手不用找。 | 既有构图须确实在伙伴可及处；不需伸手演示 |
| DLG-CUP04 | 这杯子没什么讲究，我用得有点讲究。 | 轻微自得，不补仪式流程 |
| DLG-CUP05 | 好看的杯子我也喜欢，不过先得好拿。 | 角色取舍，不需要对比画面 |
| DLG-CUP06 | 有时候捧着杯子，也没急着喝。 | 一般习惯；不要求新增捧杯姿态 |

### 多肉：好奇，但不会把照料交给用户

只使用已有多肉的可见特点；不新增长高、开花、枯萎、缺水或离线生长事实。

| 编号 | 台词 | 适用说明 |
| --- | --- | --- |
| DLG-PLANT01 | 我有时候会数它的叶子，数着数着就忘了从哪片开始。 | 一般习惯，不展示叶片计数或新增数数动画 |
| DLG-PLANT02 | 叶子厚厚的，看着就想摸。想想也行。 | 现成多肉即可，不要求实际触摸 |
| DLG-PLANT03 | 我挑这盆，有一半是因为它圆。另一半，也是。 | 轻微顽皮；只适用确实圆润的多肉 |
| DLG-PLANT04 | 这盆我越看越喜欢，也说不出哪儿好。 | 单纯喜好，不要求它长出新变化 |
| DLG-PLANT05 | 我总觉得从这边看更好看，可能是看习惯了。 | 当前静态视角即可，不要求旋转花盆 |
| DLG-PLANT06 | 照料完了，剩下的就让它慢慢长吧。 | 仅在已有完整照料结果成立时使用，不模拟即时生长 |

### 桌面：够自己用，也容得下一点乱

按现有桌面状态筛选。说“清出来”须有真实章稿结果；过程小记不因此成为收集。

| 编号 | 台词 | 适用说明 |
| --- | --- | --- |
| DLG-DESK01 | 桌上得留点空，不然我一有主意，都没地方放。 | 一般偏好，不要求新道具出现 |
| DLG-DESK02 | 我喜欢顺手一点，排得齐不齐倒还好。 | 角色取舍；仍须保持操作和画面清楚 |
| DLG-DESK03 | 这一小块归书，旁边那一小块先空着。 | 当前桌面确有对应空间，不新增划区效果 |
| DLG-DESK04 | 清出来了。先坐会儿，欣赏一下。 | 仅在清桌结果已成立时；无需新增坐下动作 |
| DLG-DESK05 | 好像还有一点歪。算了，用着不碍事。 | 静态确有安全、可用的小不齐整；不能给穿模找理由 |
| DLG-DESK06 | 没全收起来，这几样我还想看着。 | 仅当现有桌上留下了喜欢的小物；不新建收藏 |

### 小主意与小笨拙：有主见，也给自己留点余地

可用于现有的尝试或调整节点，条件不符就不用；无需为这些句子设计失误或补救动画。

| 编号 | 台词 | 适用说明 |
| --- | --- | --- |
| DLG-IDEA01 | 我有个办法。不保证，不过想试试。 | 原有故事确有尝试，不引出新的分支或用户选择 |
| DLG-IDEA02 | 这主意听着有点怪，先别急着笑。 | 仅用于确有不同寻常的小办法；不要求用户回应 |
| DLG-IDEA03 | 我刚才还没什么把握。现在有了。 | 已有尝试奏效的结果；不增加回忆分镜 |
| DLG-IDEA04 | 嗯……和我想的有一点不一样。 | 原稿已有可理解的偏差，不新造失误 |
| DLG-IDEA05 | 我想得挺好，就是手没跟上。 | 仅当原稿已有轻微笨拙，不能用于制作穿帮 |
| DLG-IDEA06 | 不太漂亮，但能用。我先留着。 | 已有结果安全可用且有小不齐整；不隐含新收集资格 |

### 休息：可以安静，也可以有点懒洋洋

用于既有休息场景或其主动阅读内容，表达伙伴自己，不代替系统计时状态，不引导延长或开启下一段。

| 编号 | 台词 | 适用说明 |
| --- | --- | --- |
| DLG-REST01 | 我先坐会儿。坐着也挺忙的，要找个舒服的姿势。 | 已有坐姿即可，不要求切换多种姿态 |
| DLG-REST02 | 现在没什么想做的。正好。 | 不要求演困倦或失落 |
| DLG-REST03 | 我本来想想下一件事，想了一下，还是先歇着。 | 角色心念，不生成待办或新章节 |
| DLG-REST04 | 这个位置一舒服，我就容易待久一点。 | 一般偏好，不改变休息时长 |
| DLG-REST05 | 发会儿呆，想到什么算什么。 | 不读取用户想法或触发便签入口 |
| DLG-REST06 | 今天的懒腰，想伸得慢一点。 | 仅适用原本已有伸懒腰场景，不为台词新增动作 |

### 采用时怎样挑

先看现成情境，再挑一句听起来像它会说的话。普通话和有点趣味的话交错使用，不连续堆笑点。将句子放在现成静态画面里读一遍：对象清楚、意思自然、不需补演，就可进入文案评审；若必须解释前史、增加动作或修改业务规则，先换句。

以上候选没有自动轮换、已读、收藏或语音功能。正式采用时复用现有本地文案与内容版本机制，并核对[E.2的注意力与触发规则](08-voice.md)。后续可改字或换句，但用户已收藏的旧文本仍按原规则保留快照。
