### E.3 节点话语库

以下编号用于内容管理，不展示给用户。每组01为首选，其余用于轮换；不是一次展示五句。先检查每组适用条件，再选择文本。

##### 首次见面（WEL）

首次打开并完成本地初始化，且没有需要恢复的活动会话；只显示一条，不阻挡开始。

| 编号 | 话语 |
| --- | --- |
| WEL01 | 很高兴见到你，先做一点也很好。 |
| WEL02 | 你好，这里可以按你的节奏来。 |
| WEL03 | 先选一个舒服的时长吧。 |
| WEL04 | 从你想做的那一小步开始就好。 |
| WEL05 | 给眼前这件事，留一小段时间吧。 |

##### 再次回来（RET）

回到准备态时使用；普通返回和隔很久返回共用，不读取缺席天数来制造剧情。恢复运行或暂停时优先显示相应状态。

| 编号 | 话语 |

| RET02 | 见到你真好，今天也按你的节奏来。 |

| RET05 | 欢迎，接下来想做的事可以慢慢选。 |

### E.4 用户主动索取的鼓励

默认点击直接显示“日常鼓励”（ASKG）中的一句。操作采用[B.6](03-ui.md#ui-copy-catalog)定稿名称；“换一种鼓励”在同一面板内切到四类选择，选定后回句子阅读，不在气泡下追加按钮。完整流程、当前类别、取消与重新打开规则统一见[A.4.1](02-features.md#encouragement-flow)。分类不是问卷，不先挡住鼓励；不提供自由聊天输入，不要求对角色作答。

用户选了“有点累了”，只允许这次使用相应文案，不把该选择保留成长期画像，也不在第二天主动提醒“你昨天很累”。若不喜欢分类，直接使用默认池就能完成完整体验。

**新增24句深层共情：每组09—14。** 与原有01—08共用入口、换句和收藏，不增加问卷、聊天步骤或新的按钮。更长的话只在用户主动要鼓励时出现，不自动插入开始、分心或休息节点；运行中的计时状态也不因阅读而自行改变。下表的“想看见的部分”是编辑意图，不是对用户的自动标签，产品中只显示话语。

这一层的写法是：先找到用户能够认领的感受或选择，再说出其中值得珍惜的部分，给未来留一点可能。并非每句都要套三步模板；一句安静的肯定也可以完整。潜力应有尝试、熟悉和发现的空间，不预告用户一定成功；人的价值当下就成立，也包含休息、离开和没有产出的时刻。

“开始有点难”与“有点累了”中的“你说”，仅指用户刚主动选择了对应入口。“想把一件事做好……”是对这种愿望的回应，不解读具体任务；“如果最近……”明确保留条件。不把未知的艰辛、孤独、天赋或善良写成已经被系统识别的事实。
