### E.3 节点话语库

以下编号用于内容管理，不展示给用户。RET／STA各5句、END 4句、ZER 2句、BRK 6句，共22句。PAU／RES／NME／NTX／BRE旧话已从资源删除，原文留在审稿记录；这些节点继续只显示固定状态。WEL／BCK／REV／EMP／MEM／NEW共30句是未接入的历史文档资产，本次未将它们作为运行台词复审或启用。实际选句从适用池直接随机抽一条，只避开该池紧邻的上句，不按编号、不要求整组轮完。

原欢迎池作为文案资产保留。当前目标首次首屏安静，欢迎笺主动阅读；不自动从本组抽句。

##### 再次回来（RET）

本轮接入准备态招呼：再次打开 App 时，有已保存的专注参与、专注记录或休息记录，当前无活动会话、无待展示的专注到期结果、页面可见且节点话开启，启动恢复成功后才随机选一句。启动中转去操作、页面隐藏或恢复失败，就取消这次招呼。首次使用保持安静；切页、回前台和恢复原段不重新欢迎，不计算缺席天数。

| 编号 | 话语 |
| --- | --- |
| RET01 | 来啦。先不急着开工。 |
| RET02 | 见到你，我挺高兴的。 |

| RET08 | 我喜欢做点小计划，也喜欢临时改主意。 |
| RET09 | 你好呀。一起待会儿吧。 |

### E.4 主动鼓励：当前运行文本与后续改稿入口

四类共39句：日常鼓励11句、开始有点难10句、刚被打断8句、有点累了10句。当前版本为 `companion-voice-v3`。不以各类凑成相同数量为目标；删掉同义换皮、空泛表态和不合场景的闲话，留下直接关心、可选的小办法与少量个人趣味。light／deep 表示阅读长度类别，不决定随机次序或亲近程度。入口、类别、换句、收藏和退出见[A.4.1](02-features.md#encouragement-flow)。

本轮逐句检查口语、实际用途与同类重复；个人小事可以表达愿意尝试、接受不完美，不能连续用读书／纸船比喻同一条道理。每次打开使用新的随机种子，之后每次触发也直接抽取；允许尚未读完整组就再次遇见某句，但相邻两次不相同。

**改稿时逐条检查。** 一般习惯、偏好可以跨活动；“刚刚”“已经”“这次”等当下事实须有匹配场景与结果。伙伴自己的读书或折纸习惯，不代表用户可以跨已结束的会话接续故事。当前选句上下文尚未绑定具体活动和过程，接入具体动作句前必须补条件，或改成不虚构当下的表达。

一条语句的身份与版本分开维护：同一内容的小修可更新版本，含义或用途改变时重新判断是否需要新ID。保存过的旧收藏沿原文本快照重读，不用本页新版覆盖。解析器已去掉每类14句的固定上限，校验合法身份、状态、事实和每类主动支持在所有声明状态下至少两句可用；扩充仍须同时核对文案与适用范围。
